# 🎨 高数下册图像化学习助手

> 一个为“图像化 + 理解驱动”型学习者量身定制的高等数学 AI 导师。

## 📚 项目简介
这是一个从零开始学习高等数学（下册）的完整辅助路径，使用**费曼学习法**和**视觉化优先**原则，将抽象的多元微积分概念转化为直观的、可想象的教学内容。

## 🎯 学习目标
- 建立对多元函数、重积分、曲线曲面积分的**几何直觉**
- 理解无穷级数与微分方程的**核心思想与应用场景**
- 掌握从“几何直观”到“严格公式”的自然过渡方法
- 利用 AI 导师获得**个性化、图像化**的实时讲解与反馈

## 🌟 特色
- **费曼学习法**：12岁小孩也能懂的生活类比解释
- **图像化优先**：每个概念都先用文本描述几何画面，再给公式
- **AI 实时互动**：搭配 Streamlit 应用，随时随地获得个性化讲解
- **渐进式学习**：从简单到复杂，从直觉到严谨，平滑过渡
- **互动验证**：每个文档包含思考题，AI 可批改并提供视觉化反馈
- **可运行的代码**：关键概念附带 Python/Matplotlib 可视化代码

## 🛠️ 使用方法
1. 按照目录顺序学习，或直接跳到感兴趣的章节。
2. 每个文档都包含思考题，建议先尝试回答，再借助 AI 导师验证。
3. 配合我们的 **Streamlit 高数学习助手** 使用，获得动态、个性化的讲解与练习。
4. 章节文档中出现的所有概念，都可以在 AI 助手中追问：“请用图像化方式重新讲解……”

## 📝 学习原则
- **12岁小孩也能懂**：使用日常生活类比（登山、刷漆、地毯……）
- **拆成原子知识点**：每个概念都拆到最基础、最可理解
- **不出现陌生词汇**：新术语立即解释，拒绝“知识诅咒”
- **用提问引导**：每节都以一个启发性问题开始
- **类比优先**：先类比再技术解释，先画面再公式
- **视觉化**：用文本描述图形、用代码生成图形
- **递进式**：从简单到复杂，从一维到高维
- **互动式**：包含思考题和 AI 导师的即时反馈
