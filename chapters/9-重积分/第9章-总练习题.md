## 📝 总练习题

### 1. 计算下列二重积分

**(1)** `∬_D (1 + x) sin y dσ`，其中 D 是顶点分别为 `(0,0), (1,0), (1,2), (0,1)` 的梯形闭区域；

**(2)** `∬_D (x² - y²) dσ`，其中 D 是闭区域：`0 ≤ y ≤ sin x, 0 ≤ x ≤ π`；

**(3)** `∬_D (y² + 3x - 6y + 9) dσ`，其中 D 是闭区域：`x² + y² ≤ R²`。

### 2. 交换下列二次积分的次序

**(1)** `∫₀⁴ dy ∫_{-√(4-y)}^{(y-4)/2} f(x, y) dx`

**(2)** `∫₀¹ dx ∫_{√x}^{1+√(1-x²)} f(x, y) dy`

**(3)** `∫_{-√2}^{√2} dx ∫_{x²}^{4-x²} f(x, y) dy`

### 3. 抽象函数与二重积分

设函数 `f(x)` 在 `[0, 1]` 上连续，且有 `∫₀¹ f(x) dx = A`，求
$$\int_0^1 dx \int_0^1 f(x) f(y) \, dy.$$

### 4. 可分离变量的二重积分

求 `∬_D ln(x + √(1 + x²)) e^y dx dy`，其中 `D: |x| ≤ 1, |y| ≤ 1`。

### 5. 计算下列三重积分

**(1)** `∭_Ω z² dV`，其中 Ω 是两个球 `x² + y² + z² ≤ R²` 和 `x² + y² + z² ≤ 2Rz` (R > 0) 的公共部分；

**(2)** `∭_Ω (x² + y² + z) dV`，其中 Ω 是由曲线 `{y² = 2z, x = 0}` 绕 z 轴旋转一周而成的曲面与平面 `z = 4` 所围成的立体；

**(3)** 求椭球体 `x²/a² + y²/b² + z²/c² ≤ 1` 的体积。

### 6. 重心应用

在均匀的半径为 R 的半圆形薄板的直径另一边要接上一个一边与直径等长的同样材料的均匀矩形薄板，为了使整个均匀薄板的重心恰好落在圆心上，问接上去的均匀矩形薄板另一边的长度应是多少？

### 7. 转动惯量应用

求由抛物线 `y = x²` 及直线 `y = 1` 所围成的均匀薄板（面密度为常数 ρ）对于直线 `y = -1` 的转动惯量。


## 🧠 解题指引（使用 AI 助手）

**如何使用 AI 助手高效复习总练习题？**

1. **先独立思考，再求助 AI**。尝试自己做一遍，遇到卡壳的题目，不要直接看答案。
2. **把具体题目和你的思路一起发给 AI**。例如：
   > “总练习题第1题(3)：D是圆域，被积函数含y²和x项，我想用极坐标做，我的思路是...，请帮我检查定限对不对。”
3. **让 AI 帮你诊断错误类型**。AI 会判断你是**定限错误**、**坐标系选择错误**还是**计算错误**。
4. **针对薄弱点回顾章节**。AI 会建议你回到具体哪一节重新学习。

**重点题型分析**：

- **第1题**：基础二重积分计算，注意选择合适的积分次序和坐标系。
  - (1) 梯形区域，直角坐标，注意积分限的确定。
  - (2) 被积函数可分离，可化为二次定积分乘积。
  - (3) 圆域 + 被积函数含 `x² + y²` 项，**极坐标**是自然选择。
- **第2题**：**交换积分次序**的经典练习，必须先画出积分区域 D 的草图，找出边界的正确表达式。
- **第3题**：抽象函数的二重积分，利用**积分与变量记号无关**的性质，将二重积分化为两个独立定积分的乘积。
- **第4题**：**可分离变量**的二重积分。被积函数是 `g(x)·h(y)`，积分区域是矩形，可直接拆成两个定积分相乘。注意 `ln(x + √(1+x²))` 是奇函数，在对称区间上积分为零。
- **第5题**：三重积分综合题。
  - (1) 两球体公共部分，需判断用**球面坐标**，注意 φ 的积分限。
  - (2) 旋转体，用**柱面坐标**最方便。
  - (3) 椭球体积，可用广义球坐标变换 `x = aρ sinφ cosθ` 等，雅可比行列式为 `abc ρ² sinφ`。
- **第6题**：**重心计算的应用题**。设矩形另一边长为 L，分别计算半圆和矩形的静力矩，令总重心在圆心（即 `x_G = 0`），解方程求 L。
- **第7题**：**转动惯量**计算。薄板对直线 `y = -1` 的转动惯量公式为 `∬_D (y + 1)² ρ dσ`。注意：**距离是点到直线的垂直距离**，这里是 `|y - (-1)| = y + 1`。
