## 🎨 生活类比

**常系数线性差分方程：每个月的账单，遵循一个固定的“利息规则”**

上一节我们知道，差分方程描述的是离散时间点上的变化规律。现在，我们遇到一类最常见、也最容易系统求解的差分方程：**常系数线性差分方程**。

想象你有一个银行账户，每个月银行会根据一个**固定的规则**来计算这个月的余额。例如：
- “这个月的余额 = 2 × 上个月的余额 - 0.5 × 上上个月的余额 + 1000 块（每月固定存入）”。
这就是一个二阶常系数线性差分方程。系数 `2` 和 `-0.5` 是常数（**常系数**），余额之间是线性关系（**线性**）。

这类方程的求解和常系数线性微分方程**完全平行**！我们同样有一把“万能钥匙”——**特征根法**。只不过，微分方程的解是 `e^{rx}`，而差分方程的解是 `λⁿ`。

**一句话理解**：常系数线性差分方程是离散世界中“最规矩”的递推关系，求解它的核心是用 `λⁿ` 试解，解出特征根后直接写出通解。


## 🧭 几何直观

- **解的形式与特征根**：
  - **不同实根**：解是 `λ₁ⁿ` 和 `λ₂ⁿ` 的组合。如果 `|λ| > 1`，对应的是指数增长；如果 `|λ| < 1`，对应的是指数衰减。
  - **重根**：通解中出现 `n λⁿ`。这个额外的 `n` 与微分方程中重根时出现 `x e^{rx}` 完全对应，都是为了“撑开”第二个线性无关解。
  - **共轭复根**：解是 `rⁿ (C₁ cos βn + C₂ sin βn)`。如果 `r = 1`，就是纯粹的振荡（正余弦）；如果 `r < 1`，是衰减振荡；如果 `r > 1`，是放大振荡。
- **通解结构**：和微分方程完全一样，非齐次通解 = 齐次通解 + 非齐次一个特解。齐次通解描述系统的“自然行为”，非齐次特解描述“外力驱动”。
- **待定系数法**：因为 `λⁿ`、`n^m`、`cos βn` 这些函数在差分运算下形式不变（类似导数），所以我们可以“猜测”特解的形式，通过代入方程定出系数。


## 📐 严格定义

### 13.2.1 线性差分方程解的性质

**定理 13.2.1（齐次通解结构）**
若 `y₁(n), ..., y_k(n)` 是 k 阶齐次方程 `y_{n+k} + p₁ y_{n+k-1} + ... + p_k y_n = 0` 的 k 个线性无关特解，则通解为 `y(n) = C₁ y₁(n) + ... + C_k y_k(n)`。

**定理 13.2.2（非齐次通解结构）**
非齐次通解 = 齐次通解 + 非齐次一个特解：`y(n) = Y(n) + ỹ(n)`。

**定理 13.2.3（叠加原理）**
若非齐次项 `q(n) = a q₁(n) + b q₂(n)`，则特解也可叠加。

### 13.2.2 常系数线性齐次差分方程的解

**二阶齐次方程**：`y_{n+2} + p₁ y_{n+1} + p₂ y_n = 0`。

尝试 `y_n = λⁿ`，得**特征方程**：`λ² + p₁ λ + p₂ = 0`。

| 特征根 | 通解 |
|--------|------|
| 两不等实根 `λ₁ ≠ λ₂` | `y_n = C₁ λ₁ⁿ + C₂ λ₂ⁿ` |
| 二重实根 `λ₁ = λ₂ = λ` | `y_n = (C₁ + C₂ n) λⁿ` |
| 共轭复根 `r e^{±iβ}` | `y_n = rⁿ (C₁ cos βn + C₂ sin βn)` |

**一阶齐次方程**：`y_{n+1} + p y_n = 0`，通解为 `y_n = C(-p)ⁿ`。

### 13.2.3 常系数线性非齐次差分方程的解

**待定系数法**（与微分方程完全平行）：

**1. `q(n) = dⁿ P_m(n)`**，`P_m` 为 m 次多项式。设特解：
$$ỹ(n) = n^k dⁿ Q_m(n),$$
其中 `Q_m` 是 m 次待定多项式，`k` 取 `d` 为特征根的重数（0, 1, 2）。

**2. `q(n) = dⁿ [P_l(n) cos βn + P_s(n) sin βn]`**，设特解：
$$ỹ(n) = n^k dⁿ [A_m(n) cos βn + B_m(n) sin βn],$$
其中 `m = max(l, s)`，`k` 取 `d e^{iβ}` 为特征根的重数（0 或 1）。


## 🧪 核心概念对比

| 概念 | 常系数线性微分方程 | 常系数线性差分方程 |
|------|---------------------|---------------------|
| **变量** | 连续 `x` | 离散 `n` |
| **试解形式** | `y = e^{rx}` | **`y_n = λⁿ`** |
| **特征方程** | `r² + p₁r + p₂ = 0` | `λ² + p₁λ + p₂ = 0` |
| **不等实根** | `y = C₁ e^{r₁x} + C₂ e^{r₂x}` | `y_n = C₁ λ₁ⁿ + C₂ λ₂ⁿ` |
| **重根** | `y = (C₁ + C₂x) e^{rx}` | `y_n = (C₁ + C₂n) λⁿ` |
| **复根 `α ± iβ`** | `y = e^{αx}(C₁ cos βx + C₂ sin βx)` | `y_n = rⁿ(C₁ cos βn + C₂ sin βn)` (r = |λ|) |
| **非齐次解法** | 待定系数法 | **待定系数法**（形式完全平行） |


## 📜 历史渊源

**问题背景**：差分方程的历史比微分方程更悠久。早在1202年，斐波那契在研究兔子繁殖时就提出了著名的递推关系 `F_{n+2} = F_{n+1} + F_n`，这正是二阶常系数线性差分方程。1728年，棣莫弗用特征根法求出了斐波那契数列的闭式解，这是差分方程理论的重要里程碑。

**关键突破**：18世纪，欧拉和拉格朗日在研究插值理论和级数时，系统发展了差分方程的解法。欧拉明确提出了用 `λⁿ` 试解常系数线性差分方程，并给出了完整的特征根分类。19世纪，乔治·布尔在《有限差分论》中完善了这一理论。

**深远影响**：在20世纪，随着数字计算机的普及，差分方程成为数值求解微分方程的标准工具。在现代经济学中，萨缪尔森的乘数-加速数模型就是二阶差分方程；在信号处理中，数字滤波器完全由线性差分方程定义。


## 🔗 发展脉络

> 递推数列（斐波那契、等差/等比数列）
> → 常系数线性差分方程的特征根法
> → 待定系数法求非齐次方程特解
> → 现代：数字信号处理（滤波器设计）、动态经济模型


## ⚠️ 本节概念的局限性

- **仅限于常系数线性方程**：对于变系数 `p_i(n)` 的线性差分方程，或非线性差分方程，特征根法失效。
- **待定系数法的适用范围有限**：只能处理非齐次项是 `dⁿ`、`nᵐ`、`cos βn`、`sin βn` 及其乘积的情况。对于更复杂的 `q(n)`，需要用其他方法（如常数变易法在差分方程中的推广）。
- **稳定性问题**：解 `λⁿ` 当 `|λ| > 1` 时会指数增长，这在工程中通常是不希望的（不稳定系统）。

> 💡 这些局限推动了**变系数差分方程**和**非线性差分方程**（混沌动力学）的研究。


## 📝 习题

### 1. 验证线性无关性并求通解

证明函数 `y₁(n) = (-1)ⁿ` 和 `y₂(n) = 2ⁿ` 是差分方程 `y_{n+2} - y_{n+1} - 2y_n = 0` 的两个线性无关的特解，并求该方程的通解。

### 2. 求二阶线性齐次差分方程的通解或特解

**(1)** `y_{n+2} + 3y_{n+1} - 10y_n = 0`

**(2)** `y_{n+2} + 2y_{n+1} - 8y_n = 0`

**(3)** `y_{n+2} - y_n = 0`

**(4)** `y_{n+2} + y_n = 0`

**(5)** `y_{n+2} - 2y_{n+1} + 5y_n = 0`

**(6)** `4y_{n+2} - 12y_{n+1} + 9y_n = 0`

**(7)** `y_{n+2} - y_{n+1} + y_n = 0, y₀ = 1, y₁ = 2`

### 3. 求二阶线性非齐次差分方程的通解或特解

**(1)** `y_{n+2} - 10y_{n+1} + 25y_n = 2ⁿ`

**(2)** `y_{n+2} + 4y_{n+1} - 5y_n = 2n - 3`

**(3)** `y_{n+2} - 3y_{n+1} + 2y_n = 1 - 2n`

**(4)** `y_{n+2} + 4y_{n+1} + 4y_n = (-2)ⁿ (n + 1)`

**(5)** `y_{n+2} - 10y_{n+1} + 25y_n = 3ⁿ + 2n + 5`

**(6)** `y_{n+2} + y_n = 3 cos(nπ/2), y₀ = 3/2, y₁ = 2`

### 4. 求线性差分方程的通解或特解

**(1)** `y_{n+2} + 3y_{n+1} = 0`

**(2)** `y_{n+1} - 2y_n = 2n² - 1`

**(3)** `y_{n+1} - y_n = n + 3`

**(4)** `y_{n+1} - 3y_n = 3ⁿ`

**(5)** `y_{n+1} - 2y_n = -cos 2n`

**(6)** `y_{n+1} + 2y_n = 2n - 1 + eⁿ`

**(7)** `y_{n+1} + 2y_n = 3·2ⁿ, y₀ = 4`

**做题步骤建议：**
1. **写特征方程**：将 `y_{n+k}` 替换为 `λ^k`，得到特征方程。
2. **求特征根**：解代数方程。
3. **写齐次通解**：根据特征根类型（不等实根、重根、复根）写出对应的通解形式。
4. **求非齐次特解**（如果需要）：
   - 根据 `q(n)` 的形式判断是哪种类型。
   - 设出含待定系数的特解形式（注意是否需要乘 `n^k`）。
   - 代入原差分方程，比较系数，求出待定系数。
5. **写出完整通解**：齐次通解 + 非齐次特解。
6. **求特解**：利用初始条件确定任意常数的值。
7. 打开 [AI 高数学习助手](https://math-learning-assistant.streamlit.app/)，输入答案让 AI 诊断。

**常见误区提醒：**
- ❌ **混淆 λ 和 eʳ**：差分方程的特征根是 `λ`，解是 `λⁿ`；微分方程的特征根是 `r`，解是 `e^{rx}`。
- ❌ **重根时忘记乘 n**：`λ₁ = λ₂ = λ` 时通解是 `(C₁ + C₂ n) λⁿ`，不是 `C₁ λⁿ + C₂ λⁿ`。
- ❌ **复根时漏掉 rⁿ**：`r` 是复根的模，即 `r = |λ|`。通解是 `rⁿ (C₁ cos βn + C₂ sin βn)`，不能漏掉 `rⁿ`。
- ❌ **待定系数法设特解形式不正确**：非齐次项含 `dⁿ` 时，如果 `d` 恰是特征根，必须乘 `n^k`。
