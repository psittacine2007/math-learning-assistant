## 🎨 生活类比

**正项级数：永不后退的蜗牛**

上一节我们认识了无穷级数，但那些项可正可负，部分和可能来回振荡，不好把握。现在，我们遇到一种最“友好”的级数：**正项级数**。它的所有项 `u_n ≥ 0`。

这就像一只**只能前进、绝不后退**的蜗牛。它沿着一条直线往前爬，每一步的距离 `u_n` 都非负。

- 它爬过的总距离 `S_n = u_1 + u_2 + ... + u_n` 只会**单调增加**，永远不会减少。
- 关键问题是：它会不会爬出有限的界限？
  - 如果前方有一堵**不可逾越的墙**（部分和数列 `{S_n}` **有上界**），那么无论它怎么爬，总距离最终会收敛到一个有限值。这就是收敛。
  - 如果前方**一马平川**，没有任何上界，它就会爬到无穷远。这就是发散。

**如何判断这堵“墙”存不存在？**
- **比较判别法**：找另一只已知能或不能越界的蜗牛（已知敛散性的级数）做参照。如果我们的蜗牛每步都比那只越界的蜗牛还大，那它也一定越界（发散）；如果它每步都比一只不越界的蜗牛还小，那它也一定被墙挡住（收敛）。
- **比式判别法**：看蜗牛**疲惫的速度**。如果后一步比前一步缩小的比例最终小于某个小于1的数（即 `u_{n+1}/u_n ≤ q < 1`），那么它越走越慢，总距离有界，一定收敛。这就像几何级数，每步按比例缩减。
- **根式判别法**：直接看第 n 步的“平均步长” `√[n]{u_n}`。如果这个值最终小于 1，那么总距离也收敛。


## 🧭 几何直观

- **部分和的几何图像**：正项级数的部分和 `S_n` 是数轴上一个**单调不减**的序列。它要么趋于一个有限极限（收敛），要么趋于 `+∞`（发散）。它永远不会振荡。
- **比较判别法的直观**：你有一个形状不规则的湖泊（正项级数 `∑ u_n`），你想知道它的总面积（和）。如果你能把它完全装进一个已知面积的圆盘（收敛的正项级数 `∑ v_n`）里，那它的面积必有限。如果它完全包含了一个已知面积为无穷的区域，那它必为无穷。
- **p 级数与几何级数**：`p` 级数 `∑ 1/n^p` 和几何级数 `∑ aq^{n-1}` 是比较判别法的两大基准。
  - `p` 级数：当 `p > 1` 时收敛，`p ≤ 1` 时发散。`p` 越大，通项衰减越快。
  - 几何级数：`|q| < 1` 时收敛，`|q| ≥ 1` 时发散。通项衰减速度是指数级的。


## 📐 严格定义

### 11.2.1 正项级数的收敛准则

若级数 `∑ u_n` 满足 `u_n ≥ 0` (n = 1, 2, ...)，则称为**正项级数**。

**定理 11.2.1（正项级数收敛的充要条件）**
正项级数 `∑ u_n` 收敛 ⇔ 其部分和数列 `{S_n}` **有上界**。

### 11.2.2 比较判别法

**定理 11.2.2（基本比较判别法）**
设 `∑ u_n` 和 `∑ v_n` 都是正项级数，且 `u_n ≤ v_n` (n = 1, 2, ...)。
1. 若 `∑ v_n` 收敛，则 `∑ u_n` 收敛；
2. 若 `∑ u_n` 发散，则 `∑ v_n` 发散。

**推论（极限比较判别法）**
若 `lim_{n→∞} u_n / v_n = l` (0 ≤ l ≤ +∞)，则：
- `0 < l < +∞`：`∑ u_n` 与 `∑ v_n` 同敛散。
- `l = 0`：若 `∑ v_n` 收敛，则 `∑ u_n` 收敛。
- `l = +∞`：若 `∑ v_n` 发散，则 `∑ u_n` 发散。

### 11.2.3 比式判别法和根式判别法

**定理 11.2.3（比式判别法，达朗贝尔判别法）**
设 `∑ u_n` 为正项级数，`lim_{n→∞} u_{n+1} / u_n = ρ`。
- 若 `ρ < 1`，级数收敛；
- 若 `ρ > 1` 或 `ρ = +∞`，级数发散；
- 若 `ρ = 1`，**无法判定**。

**定理 11.2.4（根式判别法，柯西判别法）**
设 `∑ u_n` 为正项级数，`lim_{n→∞} √[n]{u_n} = ρ`。
- 若 `ρ < 1`，级数收敛；
- 若 `ρ > 1` 或 `ρ = +∞`，级数发散；
- 若 `ρ = 1`，**无法判定**。


## 🧪 核心概念对比

| 判别法 | 考察对象 | 收敛条件 | 发散条件 | 失效情况 |
|--------|----------|----------|----------|----------|
| **必要条件** | `u_n` | `u_n → 0` | `u_n ↛ 0` | `u_n → 0` 不一定收敛 |
| **比较判别法** | `u_n` vs `v_n` | `u_n ≤ v_n` 且 `∑ v_n` 收敛 | `u_n ≥ v_n` 且 `∑ v_n` 发散 | 找不到合适的 `v_n` |
| **极限比较法** | `u_n / v_n` | 比值 `l ∈ (0, +∞)` 且 `∑ v_n` 收敛 | 比值 `l ∈ (0, +∞)` 且 `∑ v_n` 发散 | `l = 0` 或 `l = +∞` 需另外判断 |
| **比式判别法** | `u_{n+1}/u_n` | `ρ < 1` | `ρ > 1` | `ρ = 1`（如 p 级数） |
| **根式判别法** | `√[n]{u_n}` | `ρ < 1` | `ρ > 1` | `ρ = 1`（如 p 级数） |


## 📜 历史渊源

**问题背景**：17-18世纪，数学家们在研究函数展开为幂级数（如牛顿二项式定理、泰勒级数）时，迫切需要判断这些级数在哪些点上收敛。早期的级数大多是正项级数（如 `∑ x^n` 当 `x > 0` 时），因此正项级数的收敛性判别成了首要问题。

**关键突破**：雅各布·伯努利在17世纪末研究了调和级数的发散性。柯西在19世纪20年代建立了级数收敛的严格理论，提出了正项级数的比较判别法、根式判别法和柯西凝结判别法。达朗贝尔在18世纪提出了比值判别法。这些方法的实质都是将待判级数与已知的几何级数或 p 级数进行比较。

**深远影响**：正项级数的判别法是整个无穷级数理论的基础。它不仅在数学分析中至关重要（如判断幂级数的收敛半径），在物理学中的微扰理论、计算机科学中的算法复杂度分析（级数求和用于估计循环次数）中都有直接应用。


## 🔗 发展脉络

> 几何级数、调和级数（敛散性基准）
> → 正项级数收敛准则（部分和有界）
> → 比较判别法（与已知级数比较）
> → 比式判别法、根式判别法（基于通项自身的性质）
> → 现代：拉比判别法、高斯判别法等更精密的判别法


## ⚠️ 本节概念的局限性

- **只适用于正项级数**：如果级数含有负项，不能直接使用这些判别法，需要用绝对收敛或交错级数的理论。
- **`ρ = 1` 时失效**：比式判别法和根式判别法对于衰减速度“很慢”的级数（如 p 级数）完全无效。此时需要更精密的判别工具。
- **需要基准**：比较判别法需要已知敛散性的级数作为“尺子”，而这把尺子（几何级数、p 级数）的选择需要经验。

> 💡 这些局限推动了**一般项级数判别法**（莱布尼茨判别法、绝对收敛理论）和**更精密的判别法**（拉比判别法、高斯判别法）的发展。

**(5)** `∑_{n=1}^∞ n/√(n² + 2n)`

**(6)** `∑_{n=1}^∞ 1/(1 + aⁿ)` (a > 0)

### 2. 用比式或者根式判别法判别下列级数的敛散性

**(1)** `∑_{n=1}^∞ 2ⁿ/n!`

**(2)** `∑_{n=1}^∞ (n/(2n+1))²`

**(3)** `∑_{n=1}^∞ 3ⁿ·n!/nⁿ`

**(4)** `∑_{n=1}^∞ (10+n)!/(2n+1)!`

**(5)** `∑_{n=1}^∞ n²/3ⁿ`

**(6)** `∑_{n=1}^∞ n tan(π/(2n+1))`

**(7)** `∑_{n=1}^∞ n² sin²(2/n)`

**(8)** `∑_{n=1}^∞ (b/a_n)ⁿ`，其中 `a_n → a (n→∞)`，a, b 均为正数

### 3. 判别下列级数的敛散性

**(1)** `∑_{n=1}^∞ 1/√(n(n²+1))`

**(2)** `∑_{n=1}^∞ (1·3·5···(2n-1))/(2·5·8···(3n-1))`

**(3)** `∑_{n=1}^∞ n^{10}/(2 + 1/n)`

**(4)** `∑_{n=1}^∞ 1/(1 + αn²)` (α > 0)

**(5)** `∑_{n=1}^∞ (n+1)/(n(n+2))`

**(6)** `∑_{n=1}^∞ √((n+1)/n)`

**(7)** `∑_{n=1}^∞ 1/(na + b)` (a > 0, b > 0)

### 4. 证明题

设 `a_n ≥ 0` 且 `{n a_n}` 有界，证明级数 `∑ a_n²` 收敛。

### 5. 利用级数收敛的必要条件证明

**(1)** `lim_{n→∞} nⁿ/(n!)² = 0`

**(2)** `lim_{n→∞} (2n)!/(aⁿ n!) = 0` (a > 1)

### 6. 思考题

设级数 `∑ 1/n^{1+1/n}`，由于 `1 + 1/n > 1`，是否能用 p 级数的敛散性判断该级数是收敛的？

### 7. 判断题

设 `∑ u_n` 是正项级数，如果 `u_{n+1}/u_n < 1`，则级数 `∑ u_n` 收敛，这个论断是否正确？请说明理由。

### 8. 敛散性关系

设有正项级数 `∑ u_n`，以下论断是否正确？

**(1)** 如果 `∑ u_n` 收敛，则 `∑ u_n²` 也收敛；

**(2)** 如果 `∑ u_n` 发散，则 `∑ u_n²` 也发散。

正确证明，不正确请举反例说明。

### 9. 证明题

试证明，对于正项级数 `∑ u_n`，如果存在 `N ∈ ℕ⁺`，当 `n > N` 时，有 `u_{n+1}/u_n > 1`，则 `∑ u_n` 发散。

**做题步骤建议：**

   - 通项含 `n` 次方 `(u_n)^n` → 优先用**根式判别法**。
   - 通项可比较于 `p` 级数 `1/n^p` 或几何级数 `aⁿ` → 用**比较判别法**（或其极限形式）。
3. **比式/根式失效时**（`ρ = 1`）：改用比较判别法，寻找与 p 级数的等价无穷小关系。

**常见误区提醒：**
- ❌ **`ρ = 1` 直接判定收敛/发散**：这是最致命的错误！`ρ = 1` 时比式和根式判别法**失效**。
- ❌ **比式判别法条件误解**：需要极限值 `ρ < 1` 才收敛，不仅是 `u_{n+1}/u_n < 1`（如 `u_n = 1/n` 满足但发散）。
- ❌ **比较判别法放缩方向搞反**：要证收敛，需放大通项；要证发散，需缩小通项。
