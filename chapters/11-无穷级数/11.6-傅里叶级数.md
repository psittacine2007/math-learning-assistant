## 🎨 生活类比

**傅里叶级数：把一首复杂的交响乐，分解为各个乐器演奏的纯音**

泰勒级数就像用无穷多个“幂函数积木”来拼凑一个函数。但这要求函数非常光滑（无穷次可微）。

现在，我们面对的是另一种更常见的函数：**周期函数**。就像一首不断循环播放的交响乐，它的波形弯弯曲曲，甚至可以有跳跃和尖角（比如电子设备中的矩形波）。

傅里叶发现了一个惊人的事实：**任何周期性的复杂波动，无论它看起来多么不规则，都可以分解为一系列最简单、最纯粹的简谐振动（正弦波和余弦波）的叠加！**

- **纯音（简谐振动）**：就像一把音叉发出的单一频率的声音，它的波形是完美的正弦曲线 `sin(nx)` 或余弦曲线 `cos(nx)`。
- **复杂周期音（如小提琴声）**：它由基音（`n=1` 的纯音，决定音高）和无数个泛音（`n=2, 3, 4...` 的纯音，决定音色）叠加而成。

**傅里叶级数**就是告诉我们：如何从一个复杂的周期信号中，分解出每一个纯音的**强度**（也就是系数 `a_n` 和 `b_n`）。这些强度就是信号的“**频谱**”，是信号的指纹。

**一句话理解**：傅里叶级数 = `f(x) = a₀/2 + ∑ (a_n cos nx + b_n sin nx)`。它用无限多个正余弦波的叠加来表示一个周期函数。


## 🧭 几何直观

- **正交性：声音的“独立性”**：三角函数系 `{1, cos nx, sin nx}` 在 `[-π, π]` 上具有**正交性**。这意味着，任意两个不同频率的纯音在长时间内的乘积的积分为零。它们就像三维空间中的坐标轴 `x, y, z` 一样，是完全独立的、互不干扰的“基底”。
- **傅里叶系数就是“坐标”**：正因为三角函数系是正交的，我们可以像在空间中用坐标表示向量一样，把函数 `f(x)` 分解到这一组三角函数“坐标轴”上。系数 `a_n` 和 `b_n` 就是函数在这个正交基上的**投影**（坐标值）。`a_n = (1/π) ∫ f(x) cos nx dx` 这个公式，本质上就是求“函数向量” `f(x)` 在“基底向量” `cos nx` 方向上的投影长度。
- **狄利克雷收敛定理的直观**：如果函数 `f(x)` 在一个周期内只有有限个跳跃间断和有限个“扭折”（极值点），那么它的傅里叶级数**处处收敛**。在连续点，级数收敛于函数值；在跳跃间断点，级数收敛于跳跃前后的**平均值**。


## 📐 严格定义

### 11.6.1 三角级数，三角函数系的正交性

**三角函数系** `{1, cos x, sin x, cos 2x, sin 2x, …}` 在区间 `[-π, π]` 上具有**正交性**：
- 任意两个不同函数的乘积在 `[-π, π]` 上的积分为零。
- 每个函数自身的平方在 `[-π, π]` 上的积分不为零。

### 11.6.2 周期为 `2π` 的函数的傅里叶级数

设 `f(x)` 是以 `2π` 为周期的函数，其**傅里叶系数**为：

$$a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx \, dx \quad (n = 0, 1, 2, \dots)$$

$$b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx \, dx \quad (n = 1, 2, \dots)$$

**傅里叶级数**记为：

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx).$$

**定理 11.6.1（狄利克雷收敛定理）**
若 `f(x)` 在 `[-π, π]` 上满足：
1. 连续或只有有限个第一类间断点；
2. 最多只有有限个极值点。

则其傅里叶级数处处收敛，且：
- 在连续点处，和等于 `f(x)`。
- 在间断点处，和等于 `[f(x-0) + f(x+0)] / 2`。

**正弦级数与余弦级数**：
- 若 `f(x)` 为奇函数，则 `a_n = 0`，展开为正弦级数。
- 若 `f(x)` 为偶函数，则 `b_n = 0`，展开为余弦级数。
- 对于定义在 `(0, π]` 上的函数，可通过**奇延拓**或**偶延拓**，分别展开为正弦级数或余弦级数。

### 11.6.3 周期为 `2l` 的函数的傅里叶级数

令 `t = πx/l`，可将周期为 `2l` 的函数转化为周期为 `2π` 的函数，系数公式为：

$$a_n = \frac{1}{l} \int_{-l}^{l} f(x) \cos \frac{n\pi x}{l} \, dx \quad (n = 0, 1, 2, \dots)$$

$$b_n = \frac{1}{l} \int_{-l}^{l} f(x) \sin \frac{n\pi x}{l} \, dx \quad (n = 1, 2, \dots)$$


## 🧪 核心概念对比

| 概念 | 泰勒级数 | 傅里叶级数 |
|------|---------|------------|
| **基底函数** | 幂函数 `(x-x₀)ⁿ` | 三角函数 `cos nx, sin nx` |
| **展开对象** | 在一点无穷次可微的函数 | **周期函数**（可含间断点） |
| **展开系数** | `f^{(n)}(x₀)/n!`（局部导数） | **积分**（整个周期上的平均值） |
| **收敛范围** | 以展开点为中心的对称区间 | 整个实数轴（周期延拓） |
| **对函数要求** | 非常光滑（无穷次可微） | 只需满足狄利克雷条件（可含间断） |
| **物理意义** | 局部逼近 | **频谱分解**（频域分析） |


## 📜 历史渊源

**问题背景**：18世纪中叶，数学家们研究弦振动问题时，发现一根琴弦的振动可以分解为无穷多个简谐振动（驻波）的叠加。丹尼尔·伯努利、欧拉、达朗贝尔等人为此展开了激烈的争论：是不是任何函数都可以用三角级数来表示？

**关键突破**：法国数学家傅里叶在1807年提交的关于热传导的论文中，系统地提出了将任意周期函数展开为三角级数的方法，并给出了系数公式。他还大胆地断言，即使是带有跳跃间断的函数（如方波），也可以这样展开。他的结论最初遭到拉格朗日等权威的质疑，但最终被证明是正确的。

**深远影响**：傅里叶级数是现代分析和物理学的基石。它将函数从“时域”（随时间变化的波形）变换到了“频域”（由不同频率成分组成的频谱）。MP3音频压缩、JPEG图像压缩、CT扫描、核磁共振成像（MRI）、量子力学中的波函数，本质上都依赖于傅里叶变换或其变种。


## 🔗 发展脉络

> 弦振动方程的分离变量法
> → 三角级数与三角函数系的正交性
> → 傅里叶级数（周期函数的频谱分解）
> → 傅里叶积分与傅里叶变换（非周期函数的频谱分解）
> → 现代：快速傅里叶变换（FFT）、小波分析、压缩感知


## ⚠️ 本节概念的局限性

- **仅适用于周期函数**：傅里叶级数只能处理周期函数，非周期函数需要推广到傅里叶积分/变换。
- **吉布斯现象**：在函数的跳跃间断点附近，傅里叶级数的部分和会出现过冲现象（超调量约9%），且不随项数增加而消失。
- **收敛速度**：如果函数本身不够光滑（含尖角），傅里叶系数衰减慢，级数收敛速度慢，需要取很多项才能较好地逼近原函数。

> 💡 这些局限推动了**傅里叶变换**（处理非周期信号）和**小波分析**（处理非平稳信号，能同时定位时间和频率）的发展。


## 📝 习题

### 1. 将下列以 `2π` 为周期的函数展开为傅里叶级数（在 `[-π, π]` 上的表达式）

**(1)** `f(x) = |x|` `(-π ≤ x < π)`

**(2)** `f(x) = sin²x` `(-π ≤ x < π)`

**(3)** `f(x) = 3x² + 1` `(-π ≤ x < π)`

**(4)** `f(x) = sin(ax)` （a 不是整数）

**(5)** `f(x) = e^{2x}` `(-π ≤ x < π)`

**(6)** `f(x) = { bx, -π ≤ x < 0; ax, 0 ≤ x < π }` `(a > b > 0)`

### 2. 证明傅里叶系数公式

证明周期为 `2π` 的函数 `f(x)` 的傅里叶系数也可写为：
$$a_n = \frac{1}{\pi} \int_0^{2\pi} f(x) \cos nx \, dx, \quad b_n = \frac{1}{\pi} \int_0^{2\pi} f(x) \sin nx \, dx.$$

**做题步骤建议：**
1. **判断奇偶性**：观察 `f(x)` 在对称区间上是否为奇函数或偶函数。如果是，可以直接断定 `a_n = 0` 或 `b_n = 0`，节省一半计算量。
2. **计算傅里叶系数**：
   - `a₀ = (1/π) ∫_{-π}^{π} f(x) dx`
   - `a_n = (1/π) ∫_{-π}^{π} f(x) cos nx dx`
   - `b_n = (1/π) ∫_{-π}^{π} f(x) sin nx dx`
   - 注意：如果 `f(x)` 是分段函数，积分需要分段计算。
3. **写出傅里叶级数**：`f(x) ~ a₀/2 + ∑ (a_n cos nx + b_n sin nx)`。
4. **检验间断点**：如果函数有间断点，根据狄利克雷定理，在间断点处级数收敛于左右极限的平均值。

**常见误区提醒：**
- ❌ **`a₀` 公式与 `a_n` 混淆**：`a₀` 的公式中没有分母的 `π`？公式是 `a₀ = (1/π) ∫ f(x) dx`，级数中的常数项是 `a₀/2`。
- ❌ **忘记奇偶性简化**：偶函数在对称区间上 `∫ sin nx dx = 0`，奇函数 `∫ cos nx dx = 0`，这是最重要的计算简化手段。
- ❌ **积分区间错误**：对于周期为 `2l` 的函数，系数公式中的积分限和分母中的 `l` 要相应调整。
