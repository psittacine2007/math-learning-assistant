## 📝 总练习题

### 1. 计算下列曲线积分

**(1)** `∫_L xyz ds`，L 为螺线 `x = a cos t, y = a sin t, z = bt` (`0 ≤ t ≤ 2π, 0 < a < b`)

**(2)** `∫_L (xy + yz + zx) ds`，L 为球面 `x² + y² + z² = a²` 与平面 `x + y + z = 0` 的交线

**(3)** `∫_L ds/(x - y)`，L 是直线 `y = x/2 - 2` 上从 `(0, -2)` 到 `(4, 0)` 之间的一段

**(4)** `∮_L (x dy - y dx)/(x² + 4y²)`，L 为正向椭圆 `(x - 4)²/9 + (y - 3)²/4 = 1`

**(5)** `∫_L (e^y - 12xy) dx + (xe^y - cos y) dy`，L 为曲线 `y = x²` 上从 `A(-1, 1)` 到 `B(1, 1)` 的一段

**(6)** `∫_L (e^x sin y - b(x + y)) dx + (e^x cos y - ax) dy`，a, b 为正的常数，L 为从点 `A(2a, 0)` 沿曲线 `y = √(2ax - x²)` 到点 `O(0, 0)` 的弧

**(7)** `∫_L [(3y - x) dx + (y - 3x) dy]/(x + y)³`，L 是由点 `A(π/2, 0)` 沿曲线 `y = (π/2) cos x` 到点 `B(0, π/2)` 的弧

### 2. 计算下列曲面积分

**(1)** `∬_Σ z³ dS`，Σ 为上半球面 `z = √(a² - x² - y²)` 被柱面 `x² + y² = ax` 所截得的曲面

**(2)** `∬_Σ z/ρ(x, y, z) dS`，Σ 为椭球面 `x²/2 + y²/2 + z²/2 = 1` 的上半部分，`ρ(x, y, z)` 为 Σ 上点 `(x, y, z)` 处的切平面到原点 `O(0, 0, 0)` 的距离

**(3)** `∬_Σ (x⁴ - y⁴ + y²z² - x²z² + 1) dS`，Σ 是圆锥 `z = √(x² + y²)` 被柱面 `x² + y² = 2x` 所截下的部分

**(4)** `∬_Σ z(cos α + y cos β + z cos γ) dS`，Σ 为椭球面 `x²/a² + y²/b² + z²/c² = 1` 的上半部分，cos α, cos β, cos γ 为其外法线方向的方向余弦

**(5)** `∬_Σ z dx dy + x dy dz + y dz dx`，Σ 为柱面 `x² + y² = 1` 被平面 `z = 0` 及 `z = 3` 所截得的在第一卦限内的部分的前侧

**(6)** `∬_Σ (8y + 1)x dy dz + 2(1 - y²) dz dx - 4yz dx dy`，Σ 是由曲线 `{z = √(y - 1), x = 0}` 绕 y 轴旋转一周所成的曲面，它的法向量与 y 轴正向的夹角大于 `π/2`

**(7)** `∬_Σ √(x² + y² + z²) (x dy dz + y dz dx + z dx dy)`，Σ 为曲面 `x² + y² + z² = R²` 的外侧

**(8)** `∬_Σ x³ dy dz + [(1/z) f(y/z) + y³] dz dx + [(1/y) f(y/z) + z³] dx dy`，其中 `f(u)` 一阶连续可导，Σ 为锥面 `y² + z² - x² = 0 (x > 0)` 与球面 `x² + y² + z² = 1`，`x² + y² + z² = 4` 所围立体表面的外侧

### 3. 验证曲线积分与路径无关，并求其值

**(1)** `∫_{(0,0)}^{(a,b)} e^x (cos y dx - sin y dy)`

**(2)** `∫_{(1,1,1)}^{(2,3,-4)} x dx + y² dy - z³ dz`

**(3)** `∫_{(x₁,y₁,z₁)}^{(x₂,y₂,z₂)} (x dx + y dy + z dz)/√(x² + y² + z²)`，其中 `(x₁, y₁, z₁), (x₂, y₂, z₂)` 在球面 `x² + y² + z² = R²` 上

### 4. 确定参数使表达式为全微分

试确定 a, b 的值，使 `[(ax + y)/(x² + y²)] dx - [(x - y + b)/(x² + y²)] dy` 是某函数 `u(x, y)` 的全微分，并求出这样的一个原函数。

### 5. 证明不等式

设 `f(x)` 为正值连续函数，试证不等式 `∫_L [-y/f(x)] dx + x f(y) dy ≥ 2πa²`，其中 L 是圆周 `(x - a)² + (y - a)² = a² (a > 0)` 取逆时针方向。

### 6. 证明体积公式

试证：若 Σ 是光滑的封闭曲面，且它围成的立体的体积为 V，则有 `V = (1/3)∬_Σ (x cos α + y cos β + z cos γ) dS`，其中 cos α, cos β, cos γ 是曲面 Σ 的外法线的方向余弦。

### 7. 流体流量计算

已知流体速度 `V = xy i + yz j + xz k`，求由平面 `z = 1, x = 0, y = 0` 和锥面 `z² = x² + y²` 所围成的立体在第一卦限部分向外流出的流量。

### 8. 力做功计算

求力 `F = y i + z j + x k` 沿有向闭曲线 L 所做的功，其中 L 为平面 `x + y + z = 1` 被三个坐标面所截成的三角形的边界，从 z 轴正向看去，沿顺时针方向。


## 🧠 解题指引（使用 AI 助手）

**如何使用 AI 助手高效复习总练习题？**

1. **先独立思考，再求助 AI**。尝试自己做一遍，遇到卡壳的题目，不要直接看答案。
2. **把具体题目和你的思路一起发给 AI**。例如：
   > “总练习题第1题(6)：被积函数中有a和b，L是半圆弧，我想用格林公式补线计算，我的思路是...，请帮我检查。”
3. **让 AI 帮你诊断错误类型**。AI 会判断你是**公式选择错误**、**符号方向错误**、**积分路径选择不当**还是**计算错误**。
4. **针对薄弱点回顾章节**。AI 会建议你回到具体哪一节重新学习。

**重点题型分析**：

- **第1题**：曲线积分综合题。
  - (1)(2)(3) 是第一型曲线积分，注意弧长微元 `ds` 的计算。
  - (4) 用格林公式，注意判断奇点位置（分母为零的点是否在椭圆内部）。
  - (5)(6) 验证是否与路径无关，或者用格林公式补线。
  - (7) 判断是否全微分，或选择合适路径。
- **第2题**：曲面积分综合题。
  - (1)(2)(3)(4) 是第一型曲面积分，注意面积微元 `dS` 的计算和投影方法。
  - (5)(6) 是第二型曲面积分，注意曲面方向和投影符号。
  - (7)(8) 考虑用**高斯公式**简化（封闭曲面取外侧）。
- **第3题**：积分与路径无关的验证和应用。核心是验证 `∂P/∂y = ∂Q/∂x`（平面）或 `rot F = 0`（空间），然后选择最方便的路径。
- **第4题**：全微分的条件。利用 `∂P/∂y = ∂Q/∂x` 确定参数 a, b，再用偏积分法求原函数。
- **第5题**：用格林公式将曲线积分化为二重积分，再用不等式放缩。
- **第6题**：高斯公式的推论（令 `P = x, Q = y, R = z` 即得）。
- **第7题**：流量 = 第二型曲面积分（封闭曲面外侧）。使用**高斯公式**转化为三重积分。
- **第8题**：力做功 = 第二型曲线积分。可用**斯托克斯公式**转化为曲面积分。
