## 📝 习题
### 1. 求下列微分方程组的通解或特解

**(1)**
dy/dx = z
dz/dx = -z - y

**(2)**
d²x/dt² + y = 0
d²y/dt² + x = 0

**(3)**
dx/dt = 2x + y
dy/dt = x + 2y

**(4)**
dx/dt = x + y
dy/dt = x - y - 2

**(5)**
d²x/dt² - 2·dy/dt + x = 0, x(0) = 0
dy/dt - x = 0, y(0) = 1
**(6)**
dx/dt + dy/dt + x + 3y = 2, x(0) = 1/4
dy/dt + x + y = t, y(0) = 5/4

### 2*. 用首次积分解下列微分方程组

**(1)**
dx / (z - y)² = dy / z = dz / y

**(2)**
dy/dx = (3x - 4z) / (2z - 3y)
dz/dx = (4y - 2x) / (2z - 3y)

**(3)**
dx / (2 + √(z - x - y)) = dy / 1 = dz / 3

**(4)**
dx / (eˣ + z) = dy / (eʸ + z) = dz / (z² - eˣ⁺ʸ)

**做题步骤建议：**
1. **消元法**（基本方法）：
   - 对其中一个方程求导，利用其他方程消去其他未知函数，化为一元高阶微分方程。
   - 解出高阶方程后，代回原方程求出其他未知函数。
2. **首次积分法**（第2*题）：
   - 对于对称形式 `dx/P = dy/Q = dz/R`，利用比例性质（如 `dx/P = d(y+z)/(Q+R)`）寻找独立积分。
   - 目标是找到两个独立的首次积分 `u(x, y, z) = C₁` 和 `v(x, y, z) = C₂`。
3. **求特解**：先求通解，再利用初始条件确定任意常数的值。
4. 打开 [AI 高数学习助手](http://localhost:8501)，输入答案让 AI 诊断。

**常见误区提醒：**
- ❌ **消元时求导次数不够**：含 `x', y'` 的方程组消元后可能是二阶方程，不要漏掉项。
- ❌ **消元过程中丢失信息**：代回原方程求第二个函数时，可能会出现新的积分常数。
- ❌ **首次积分找不全**：`n` 个方程需要找到 `n-1` 个独立的首次积分。
