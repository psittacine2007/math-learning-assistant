## 📝 总练习题

### 1. 求下列微分方程的通解

**(1)** `y' + y/x = 1/(x(x² + 1))`

**(2)** `(y - x³)dx - 2x dy = 0`

**(3)** `y'' + 4y' + 4y = e^{-2x}`

**(4)** `y'' + y' = x²`

**(5)** `y'' - 3y' + 2y = x eˣ`

**(6)** `y'' + 2y' - 3y = e^{-3x}`

**(7)** `y'' + 2y' + y = x eˣ`

**(8)** `y'' + y = x + cos x`

### 2. 求下列微分方程满足初始条件的特解

**(1)** `x dy/dx = x - y`，`y|_{x=√2} = 0`

**(2)** `x y' + (1 - x)y = e^{2x}` (0 < x < +∞)，`y(1) = 0`

**(3)** `x ln x dy + (y - ln x)dx = 0`，`y|_{x=e} = 1`

**(4)** `x y' + y = x eˣ`，`y(1) = 1`

**(5)** `x² y' + x y = y²`，`y|_{x=1} = 1`

**(6)** `(x² - 1)dy + (2xy - cos x)dx = 0`，`y|_{x=0} = 1`

### 3. 通过适当变换化为可解类型，并求解

**(1)** `dy/dx = (x + y)²`

**(2)** `y' = (x - y)² + 1`

**(3)** `dy/dx + x tan(y - x) = 1`

**(4)** `x y' + x + sin(x + y) = 0`

**(5)** `y' = a x + b y + c`

**(6)** `y'/y - (ln y)/x = x²`

**(7)** `eʸ y' - eʸ/x = x²`

**(8)** `2x y y' = y² + x tan(y²/x)`

**(9)** `dy/dx = (y² - x)/(2y(x + 1))`

**(10)** `x y' + y = y ln(xy)`

**(11)** `(3x² + 2xy - y²)dx + (x² - 2xy)dy = 0`

### 4. 三阶常系数方程

求微分方程 `y''' + 6y'' + (9 + a²)y' = 1` 的通解，其中常数 `a > 0`。

### 5. 综合题（切线条件）

设函数 `y = y(x)` 满足微分方程 `y'' - 3y' + 2y = 2eˣ`，其图形在点 `(0, 1)` 处的切线与曲线 `y = x² - x + 1` 在该点处的切线重合，求函数 `y` 的解析表达式。

### 6. 含参数的通解

求微分方程 `y'' + 4y' + 4y = e^{ax}` 之通解，其中 `a` 为实数。

### 7. 分段非齐次项

设有微分方程 $y'' - 2y = \varphi(x)$，其中

$$
\varphi(x) = 
\begin{cases} 
2, & x < 1, \\[4pt]
0, & x > 1.
\end{cases}
$$

试求在 $(-\infty, +\infty)$ 内的连续函数，使之在 $(-\infty, 1)$ 和 $(1, +\infty)$ 内都满足所给方程，且满足条件 $y(0) = 0$。

### 8. 积分方程求函数

已知连续函数 `f(x)` 满足 `f(x) = ∫₀ˣ f(t/3) dt + e^{2x}`，求 `f(x)`。

### 9. 积分方程求函数

设 `f(x) = sin x - ∫₀ˣ (x - t)f(t) dt`，其中 `f` 有二阶连续导数，求 `f(x)`。

### 10. 含参数的通解

求微分方程 `y'' + a² y = sin x` 的通解，其中常数 `a > 0`。

### 11. 变量代换化简

利用代换 `y = u/cos x` 将方程 `y'' cos x - 2y' sin x + 3y cos x = eˣ` 化简，并求出原方程的通解。

### 12. 已知一个解求特解

设 `y = eˣ` 是微分方程 `x y' + p(x)y = x` 的一个解，求此微分方程满足条件 `y|_{x=ln 2} = 0` 的特解。

### 13. 全微分方程求参数

设 `f(x)` 具有二阶连续导数，`f(0) = 0, f'(0) = 1`，且
$$[xy(x + y) - f(x)y]dx + [f'(x) + x² y]dy = 0$$
为一全微分方程，求 `f(x)` 及此全微分方程的通解。

### 14. 反函数与积分方程

设函数 `f(x)` 在 `[0, +∞)` 上可导，`f(0) = 0`，且反函数为 `g(x)`。若
$$\int_0^{f(x)} g(t) dt = x² eˣ,$$
求 `f(x)`。

### 15. 偏微分方程导出

设函数 `f(u)` 具有二阶连续导数，而 `z = f(eˣ sin y)` 满足方程
$$\frac{\partial^2 z}{\partial x^2} + \frac{\partial^2 z}{\partial y^2} = e^{2x} z,$$
求 `f(u)`。

### 16. 极限条件求函数

已知函数 `f(x)` 在 `(0, +∞)` 内可导，`f(x) > 0`，`lim_{x→+∞} f(x) = 1`，且满足
$$\lim_{h \to 0} \left( \frac{f(x + hx)}{f(x)} \right)^{1/h} = e^{1/x},$$
求 `f(x)`。

### 17. 由特解反推方程

设二阶常系数线性微分方程 `y'' + αy' + βy = γeˣ` 的一个特解为 `y = e^{2x} + (1 + x)eˣ`，试确定常数 `α, β, γ`，并求该方程的通解。

### 18. 由解反推方程

已知 `y₁ = x eˣ + e^{2x}`，`y₂ = x eˣ + e^{-x}`，`y₃ = x eˣ + e^{2x} - e^{-x}` 是某二阶线性非齐次微分方程的三个解，求此微分方程。

### 19. 初值问题

求初值问题

$$
\begin{cases} 
(y + \sqrt{x^2 + y^2})\,dx - x\,dy = 0, \quad (x > 0), \\[4pt]
y|_{x=1} = 0
\end{cases}
$$

的解。

### 20. 含参初值问题与估计

设 `f(x)` 为连续函数。
**(1)** 求初值问题 `{y' + ay = f(x), y|_{x=0} = 0}` 的解 `y(x)`，其中 `a` 是正常数；
**(2)** 若 `|f(x)| ≤ k`（`k` 为常数），证明：当 `x ≥ 0` 时，有 `|y(x)| ≤ (k/a)(1 - e^{-ax})`。

### 21. 几何应用（曲率与法线）

在上半平面求一条向上凹的曲线，其上一点 `P(x, y)` 处的曲率等于此曲线在该点的法线段 `PQ` 长度的倒数（`Q` 是法线与 `x` 轴的交点），且曲线在点 `(1, 1)` 处的切线与 `x` 轴平行。

### 22. 几何应用（切线截距）

设曲线 `L` 位于 `xOy` 平面的第一象限内，`L` 上任一点 `M` 处的切线与 `y` 轴总相交，交点记为 `A`。已知 `|MA| = |OA|`，且 `L` 过点 `(3/2, 3/2)`，求 `L` 的方程。

### 23. 几何应用（积分条件）

设对任意 `x > 0`，曲线 `y = f(x)` 上点 `(x, f(x))` 处的切线在 `y` 轴上的截距等于 `(1/x)∫₀ˣ f(t) dt`，求 `f(x)` 的一般表达式。

### 24. 几何应用（曲率条件）

设 `y = y(x)` 是一向上凸的连续曲线，其上任意一点 `(x, y)` 处的曲率为 `1/√(1 + (y')²)`，且此曲线上点 `(0, 1)` 处的切线方程为 `y = x + 1`，求该曲线的方程，并求函数 `y = y(x)` 的极值。

### 25. 几何应用综合

设 `L` 是一条平面曲线，其上任意一点 `P(x, y)`（`x > 0`）到坐标原点的距离，恒等于该点处的切线在 `y` 轴上的截距，且 `L` 经过点 `(1/2, 0)`。
**(1)** 试求曲线 `L` 的方程；
**(2)** 求 `L` 位于第一象限部分的一条切线，使该切线与 `L` 及两坐标轴所围成图形的面积最小。

### 26. 最值问题

求微分方程 `x dy + (x - 2y) dx = 0` 的一个解 `y = y(x)`，使得由曲线 `y = y(x)` 与直线 `x = 1, x = 2` 及 `x` 轴所围成的平面图形绕 `x` 轴旋转一周的旋转体体积最小。

### 27. 旋转体体积条件

设函数 `f(x)` 在 `[1, +∞)` 上连续，若有曲线 `y = f(x)`，直线 `x = 1, x = t`（`t > 1`）与 `x` 轴所围成的平面图形绕 `x` 轴旋转一周所成的旋转体体积为
$$V(t) = \frac{\pi}{3} [t² f(t) - f(1)].$$
试求 `y = f(x)` 所满足的微分方程，并求该微分方程满足条件 `y|_{x=2} = 2/9` 的解。

### 28. 混合问题（湖泊污染）

湖泊的水量为 `V`，每年排入湖泊内含污染物 `A` 的污水量为 `V/6`，流入湖泊内不含 `A` 的水量为 `V/6`，流出湖泊的水量为 `V/3`。已知 1999 年底湖中 `A` 的含量为 `5m₀`，超过国家规定指标。为了治理污染，从 2000 年初起，限定排入湖泊中含 `A` 污水的浓度不超过 `m₀/V`。问至多需经过多少年，湖泊中污染物 `A` 的含量降至 `m₀` 以内？（注：设湖水中 `A` 的浓度是均匀的。）

### 29. 几何与物理（雪堆融化）

一个半球体状的雪堆，其体积融化的速率与半球面积 `S` 成正比，比例常数 `K > 0`。假设在融化过程中雪堆始终保持半球体状，已知半径为 `r₀` 的雪堆在开始融化的 3 小时内，融化了其体积的 `7/8`，问雪堆全部融化需要多少小时？

### 30. 人口/传播模型

在某一人群中推广新技术是通过其中已掌握新技术的进行的。设该人群的总人数为 `N`，在 `t = 0` 时刻已掌握新技术的人数为 `x₀`，在任意时刻 `t` 已掌握新技术的人数为 `x(t)`（将 `x(t)` 视为连续变量），其变化率与已掌握新技术和未掌握新技术人数之积成正比，比例常数 `k > 0`，求 `x(t)`。

### 31. 追及问题（建模）

设物体 `A` 从点 `(0, 1)` 出发，以速度大小为常数 `v` 沿 `y` 轴正向运动。物体 `B` 从点 `(-1, 0)` 与 `A` 同时出发，其速度大小为 `2v`，方向始终指向 `A`，试建立物体 `B` 的运动轨迹所满足的微分方程，并写出初始条件。

### 32. 力学问题

设单位质点在水平面内作直线运动，初始速度 `v|_{t=0} = v₀`。已知阻力与速度成正比（比例常数为 1），问 `t` 为多少时此质点的速度为 `v₀/3`？并求到此时刻该质点所经过的路程。

### 33. 力学问题（仪器下沉）

从船上向海中沉放某种探测仪器，按探测要求，需确定仪器的下沉深度 `y`（从海平面算起）与下沉速度 `v` 之间的函数关系。设仪器在重力作用下，从海平面由静止开始铅直下沉，在下沉过程中还受到阻力和浮力的作用。设仪器的质量为 `m`，体积为 `B`，海水比重为 `ρ`，仪器所受的阻力与下沉速度成正比，比例系数为 `k`（`k > 0`）。试建立 `y` 与 `v` 所满足的微分方程，并求出函数关系式 `y = y(v)`。


## 🧠 解题指引（使用 AI 助手）

**如何使用 AI 助手高效复习总练习题？**

1. **先独立思考，再求助 AI**。尝试自己做一遍，遇到卡壳的题目，不要直接看答案。
2. **把具体题目和你的思路一起发给 AI**。例如：
   > “总练习题第1题(3)：y''+4y'+4y=e^{-2x}，特征根是重根-2，特解我设的是Ax²e^{-2x}，请帮我检查计算过程。”
3. **让 AI 帮你诊断错误类型**。AI 会判断你是**类型识别错误**、**特解形式设错**、**变换代换错误**还是**建模翻译错误**。
4. **针对薄弱点回顾章节**。AI 会建议你回到具体哪一节重新学习。

**重点题型分析**：

- **第1-2题**：基础计算题。检验一阶和高阶常系数方程的常规解法。注意识别方程类型（线性、伯努利、全微分等）。
- **第3题**：变量代换题。核心是找到合适的代换将复杂方程化为已知类型。常用代换：`u = x+y`、`u = y/x`、`u = ln y` 等。
- **第4-10题**：含参数或分段函数的方程，需要分情况讨论特征根，或利用连续性条件拼接解。
- **第8-9题**：积分方程。核心是**两边对 x 求导**，将积分方程化为微分方程，同时注意利用原积分方程提取初始条件。
- **第11-12题**：变量代换或已知解求方程。第11题按提示代换化简；第12题将 `y = eˣ` 代入方程求出 `p(x)`，再解方程。
- **第13题**：全微分条件 `∂P/∂y = ∂Q/∂x`，展开后得到关于 `f(x)` 的微分方程，解出 `f(x)` 后再求全微分方程的通解。
- **第14-16题**：综合题，涉及反函数积分、偏微分方程、极限定义等，需要灵活运用求导和微分方程知识。
- **第17-18题**：由解的结构反推方程。利用齐次通解对应特征根、非齐次特解对应非齐次项的关系。
- **第19-27题**：应用题。关键是将几何条件（切线截距、曲率、弧长、面积、体积）或物理条件“翻译”为微分方程。
- **第28-33题**：实际建模题。混合问题、融化问题、传播问题、追及问题、力学问题等，遵循“建模→求解→解释”的标准步骤。
