## 🎨 生活类比

**一阶微分方程：不同路况下的“导航仪”**

在上一节，你知道微分方程描述的是函数与它的变化率之间的关系，就像一个侦探故事。现在，我们要学习如何“破案”——即求解一阶微分方程的各种方法。

不同的方程，就像不同的道路，需要用不同的驾驶技巧来通过。

- **可分离变量型**：就像一条笔直的高速公路。车（变量 x）和路（变量 y）的影响是**完全分开**的。你只需把和 x 有关的放到一边，和 y 有关的放到另一边，然后直接“积分”过去就行了。这是最简单的情况。
- **齐次型**：就像遇到一个复杂的转盘。方程里到处都是 `y/x` 这种“复合”形式。你需要找一个当地向导（变量代换 `u = y/x`），让他把你带到一条全新的、笔直的路上。
- **一阶线性型**：就像一条稍微有坡度的公路。你可以先用“常数变易法”这把万能钥匙，把问题转化为一个简单的积分问题。
- **伯努利方程**：这是一段山路，直接爬不上去。你需要换一辆越野车（变量代换 `z = y^{1-α}`），把山路转换成公路后再行驶。
- **全微分方程**：就像有一张完整的地图。你发现整个方程恰好是某个“势函数”的全微分，这意味着你只需要找到这个势函数，答案就自然出现了。


## 🧭 几何直观

- **方向场与积分曲线**：一阶微分方程 `y' = f(x, y)` 可以在平面上每一点 `(x, y)` 画出一条短斜线，其斜率为 `f(x, y)`。这就像一片“风向图”。方程的解 `y = y(x)` 就是一条处处顺着风向流动的曲线，称为**积分曲线**。
- **通解是一族曲线**：不同的任意常数对应不同的积分曲线，它们布满了整个平面上的某个区域。特解就是经过某特定点的那一条曲线。
- **各类方程的几何对应**：
  - **可分离变量**：等倾线（斜率相等的线）是平行于坐标轴的网格。
  - **齐次型**：斜率 `f(y/x)` 只依赖于方向，因此等倾线是从原点出发的射线。这种方程的解曲线在原点附近呈现相似性。
  - **线性方程**：解的结构清晰，非齐次通解 = 齐次通解 + 非齐次特解，在几何上表现为积分曲线族可以由某一特解曲线上下平移得到。


## 📐 严格定义

### 12.2.1 可分离变量型微分方程

形如 `dy/dx = f(x)g(y)` 的方程。当 `g(y) ≠ 0` 时，可分离变量为 `dy/g(y) = f(x)dx`，两边积分得通解：
$$\int \frac{dy}{g(y)} = \int f(x) dx + C.$$

### 12.2.2 齐次型微分方程

形如 `dy/dx = φ(y/x)` 的方程。令 `u = y/x`，则 `y = xu`，`dy/dx = u + x du/dx`。代入后化为可分离变量方程：
$$x \frac{du}{dx} = \phi(u) - u.$$
解出 `u` 后代回 `y = xu` 即得通解。

### 12.2.3 可化为齐次型的微分方程

形如 `dy/dx = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂)` 的方程。
- 若 `a₁b₂ ≠ a₂b₁`，通过平移变换 `x = ξ + α, y = η + β`（(α, β) 为直线交点）化为齐次型。
- 若 `a₁b₂ = a₂b₁`，令 `u = a₂x + b₂y`，化为可分离变量方程。

### 12.2.4 一阶线性微分方程

形如 `dy/dx + p(x)y = q(x)` 的方程。对应齐次方程 `y' + p(x)y = 0` 的通解为 `y = C e^{-∫p dx}`。

非齐次方程的通解由**常数变易法**求得：
$$y = e^{-\int p dx} \left( \int q e^{\int p dx} dx + C \right).$$

### 12.2.4 续：伯努利方程

形如 `dy/dx + p(x)y = q(x)y^α`（`α ≠ 0, 1`）的方程。两边同乘 `y^{-α}`，令 `z = y^{1-α}`，化为线性方程：
$$\frac{dz}{dx} + (1-\alpha)p(x)z = (1-\alpha)q(x).$$

### 12.2.5 全微分方程

若存在 `u(x, y)` 使 `du = P dx + Q dy`，即 `∂P/∂y = ∂Q/∂x`，则方程 `P dx + Q dy = 0` 为全微分方程。通解为 `u(x, y) = C`。

求原函数 `u` 的公式：
$$u(x, y) = \int_{x_0}^x P(x, y_0) dx + \int_{y_0}^y Q(x, y) dy.$$


## 🧪 核心概念对比

| 类型 | 标准形式 | 核心解法 | 关键技巧 |
|------|----------|----------|----------|
| **可分离变量** | `y' = f(x)g(y)` | 直接分离，两边积分 | 注意 `g(y) ≠ 0` 条件 |
| **齐次型** | `y' = φ(y/x)` | 令 `u = y/x` | 化为一阶可分离变量 |
| **一阶线性** | `y' + p(x)y = q(x)` | 常数变易法 / 公式法 | 记住通解公式的结构 |
| **伯努利** | `y' + p(x)y = q(x)y^α` | 令 `z = y^{1-α}` | 化为线性方程 |
| **全微分** | `P dx + Q dy = 0`，`∂P/∂y = ∂Q/∂x` | 求原函数 `u(x, y)` | 利用积分与路径无关 |


## 📜 历史渊源

**问题背景**：17世纪末，随着微积分的创立，数学家们开始研究各种物理和几何问题中导出的微分方程。莱布尼茨和雅各布·伯努利在研究等时曲线、悬链线等问题时，发展出了分离变量法等早期解法。

**关键突破**：1696年，约翰·伯努利提出了著名的“伯努利方程”，并被他哥哥雅各布和莱布尼茨用不同方法解出。1740年前后，欧拉系统地整理了初等解法，并提出了积分因子的概念。拉格朗日在18世纪后期进一步发展了常数变易法，使其成为处理非齐次线性方程的标准工具。

**深远影响**：一阶微分方程的初等解法是微分方程理论的基石。虽然在现代，大多数实际方程无法用初等积分求解，但这些经典方法揭示了方程解的结构和几何性质，并启发了数值解法和定性理论的发展。


## 🔗 发展脉络

> 可分离变量法（最早解法）
> → 齐次型方程的变量代换
> → 一阶线性方程与常数变易法
> → 伯努利方程与全微分方程
> → 现代：定性理论与数值解法（相图分析、欧拉法、龙格-库塔法）


## ⚠️ 本节概念的局限性

- **能用初等积分求解的方程极少**：本节介绍的解法只能处理非常特殊的方程形式。绝大多数一阶微分方程无法用初等函数表示其解。
- **隐式解的局限性**：很多方程求解后得到的是隐式解 `F(x, y) = C`，无法或很难化为显式 `y = f(x)`。
- **积分因子的困难**：全微分方程的积分因子没有通用的求法，通常依赖于观察和经验。

> 💡 这些局限推动了**微分方程定性理论**（如相图分析、稳定性理论）和**数值解法**（如欧拉法、龙格-库塔法）的发展，使人们即使无法求出精确解，也能分析解的行为。


## 📝 习题

### 1. 用分离变量法求通解

**(1)** `2y dx - x dy = 0`

**(2)** `tan x dy/dx = y ln y`

**(3)** `2y y' = (1 + y²) eˣ`

**(4)** `eˣ sin y dx + (1 - eˣ) cos y dy = 0`

**(5)** `y' = e^{2x+y}`

**(6)** `(x² + 1) dy/dx - 2x = 2x eʸ`

### 2. 求齐次微分方程的通解

**(1)** `dy/dx = xy/(x² + y²)`

**(2)** `x dy/dx - x e^{y/x} - y - x = 0`

**(3)** `dy/dx = (y/x)² + y/x`

**(4)** `dy/dx = (y - x)/(x + 4y)`

**(5)** `x y y' = x² + y²`

**(6)** `2xy dx + (y² - 3x²) dy = 0`

### 3. 求线性微分方程的通解

**(1)** `dy/dx - y = eˣ`

**(2)** `y' - 2y = -2x + 3`

**(3)** `y' + y sin x = 2x e^{cos x}`

**(4)** `(x + 2) dy/dx = 4y + eˣ (x + 2)⁶`

**(5)** `dy/dx - y cot x = sin 2x`

**(6)** `x y' - (x + 2)y = x³`

### 4. 求伯努利方程的通解

**(1)** `dy/dx - x y = x³ y³`

**(2)** `dy/dx - y/x = x⁵ y^{-3}`

**(3)** `x y' + 2y = x³ eˣ y²`

**(4)** `dy/dx + 2y/(x+1) = 3(x+1)² y^{4/3}`

### 5. 判断并求全微分方程的通解

**(1)** `(2x + y)dx + (x + 4y)dy = 0`

**(2)** `[(1/y) sin(x/y) - (y/x²) cos(y/x)] dx + [(1/x) cos(y/x) - (x/y²) sin(x/y)] dy = 0`

**(3)** `(eˣ + y²)dx + 6xy dy = 0`

**(4)** `y sin(x+y)dx + [y sin(x+y) - cos(x+y)]dy = 0`

### 6. 求满足初始条件的特解

**(1)** `x y' - y ln y = 0`，`y|_{x=1} = e`

**(2)** `dy/dx = y/(2x) + x/(2y)`，`y|_{x=-1} = 2`

**(3)** `(x + y cos(y/x)) dx - x cos(y/x) dy = 0`，`y|_{x=1} = 0`

**(4)** `y' = 2xy + e^{x²} sin x`，`y|_{x=0} = 1`

### 7. 选择适当方法求通解

**(1)** `dy/dx = y/(x + y⁶)`

**(2)** `(1 + y²)dx - (xy + x³ y)dy = 0`

**(3)** `(x² - y)dx + (3y² - x)dy = 0`

**(4)** `x y² y' = x³ + y³`

**(5)** `x y' = y - x² y²`

**(6)** `y(xy + 1)dx + dy = 0`

**如何让 AI 帮你批改课本习题？**

> “习题12.2第3题(1)：dy/dx - y = eˣ，我用公式法求得 y = eˣ(x + C)，请帮我诊断。”

**做题步骤建议：**
1. **识别类型**：这是最关键的一步！根据方程的形式，判断它是可分离变量、齐次、线性、伯努利还是全微分方程。
2. **选择对应解法**：
   - **可分离变量**：分离 → 积分。
   - **齐次型**：令 `u = y/x` → 化为可分离变量 → 代回。
   - **一阶线性**：用通解公式或常数变易法。
   - **伯努利**：令 `z = y^{1-α}` → 化为线性 → 代回。
   - **全微分**：验证 `∂P/∂y = ∂Q/∂x` → 用积分公式求 `u(x, y)` → 得 `u(x, y) = C`。
3. **必要时变换自变量**：如果以 `y` 为自变量更方便，可以将方程改写为 `dx/dy` 的形式。
4. **求特解**：先求通解，再代入初始条件确定任意常数。
5. 打开 [AI 高数学习助手](http://localhost:8501)，输入答案让 AI 诊断。

**常见误区提醒：**
- ❌ **类型识别错误**：误把齐次当成线性，或把伯努利当成可分离变量。
- ❌ **积分时忘记常数**：每次不定积分都必须加上任意常数 `C`。
- ❌ **变量代换后忘记代回**：齐次型、伯努利方程解出中间变量后，必须代回原变量。
- ❌ **全微分方程漏判**：没有先验证 `∂P/∂y = ∂Q/∂x` 就盲目求解。
