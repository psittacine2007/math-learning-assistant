## 🎨 生活类比

**微分方程：侦探破案，根据“变化规律”反推“真相”**

之前我们学的大多是“已知函数，求导数”（微分法）或“已知导数，求原函数”（积分法）。现在，我们遇到一个更复杂的侦探故事。

想象你是一位侦探，来到一个案发现场。你没有直接看到罪犯（函数 `y`）长什么样，但你发现了罪犯留下的**脚印和指纹**——这些就是关于未知函数的**变化率**（导数 `y'`, `y''`）。

你找到的线索是一张纸条，上面写着：“这个未知函数和它的变化率之间，满足这样一个关系：`y' + 2xy = 4x`”。这就是一个**微分方程**——它描述的是**未知函数与其导数之间的关系**。

- **破案（求解）**：你的任务是根据这个关系，找出所有可能符合这个规律的函数。找出来的所有可能的嫌疑人名单，就是**通解**（含有一个或多个任意常数）。
- **锁定嫌犯（求特解）**：如果你的线人又给了你一条关键信息，比如“在 `x=0` 的时候，函数值必须是 `1`”（即 `y(0)=1`），这个信息就是**初始条件**。有了它，你就能从所有嫌疑犯中锁定唯一一个真凶，这就是**特解**。


## 🧭 几何直观

- **微分方程是一族曲线的“共同特征”**：微分方程 `dy/dx = 2x` 的解是 `y = x² + C`。这代表一族形状完全相同、只是在竖直方向上下平移的抛物线。微分方程本身不指定具体是哪一条，它描述的是一族曲线共有的“斜率分布规律”。
- **通解的几何意义**：通解中包含的任意常数 `C`，代表了**一族曲线**。每给 `C` 一个值，就得到其中一条特定的曲线。
- **特解的几何意义**：初始条件 `y(x₀) = y₀` 要求曲线必须经过点 `(x₀, y₀)`。特解就是从一族曲线中，挑出唯一经过该点的那一条。


## 📐 严格定义

### 1. 基本概念

- **微分方程**：含有未知函数及其导数（或微分）的方程。
- **常微分方程**：未知函数是一元函数的微分方程。
- **阶**：方程中出现的未知函数**最高阶**导数的阶数。
- **解**：代入方程后能使其成为恒等式的函数。
- **通解**：含有独立任意常数的个数等于方程阶数的解。
- **特解**：利用初始条件（或其他定解条件）确定了通解中任意常数后得到的解。
- **初始条件**：给出未知函数及其若干阶导数在某点的值。

### 2. 解的验证

将函数及其导数代入微分方程，验证等式是否恒成立。

### 3. 简单微分方程的解法——直接积分法

对于形如 `y^{(n)} = f(x)` 的方程，可通过连续 `n` 次积分求出通解。


## 📝 习题

### 1. 指出下列微分方程的阶数

**(1)** `dy/dx = 3x² + y`

**(2)** `y'' + 5y' + 6y = eˣ sin x`

**(3)** `y y'' - (y')² + (y')³ = 0`

**(4)** `(x + 2y)dx + (3x + y)dy = 0`

**(5)** `d⁴y/dx⁴ - 2 d²y/dx² + y = x⁵ - 3`

**(6)** `y³ y'' + 1 = 0`

### 2. 验证通解并求特解

验证函数 `y = 2 + Ce^{-x²}`（`C` 是任意常数）是微分方程 `dy/dx + 2xy = 4x` 的通解，并求满足初始条件 `y(0) = 1` 的特解。

### 3. 验证解

验证下列函数都是微分方程 `y'' - 2y' + y = 0` 的解：

**(1)** `y = eˣ`

**(2)** `y = x eˣ`

**(3)** `y = C₁ eˣ + C₂ x eˣ`（`C₁, C₂` 为任意常数）

### 4. 求通解

**(1)** `dy/dx = 2x`

**(2)** `dy/dx = tan x`

**(3)** `d²y/dx² = 6`

**(4)** `eˣ d²y/dx² + 1 = 0`

### 5. 求特解

**(1)** `dy/dx = 1/x`，`y|_{x=1} = 1`

**(2)** `d²y/dx² = sin x + 2`，`y|_{x=0} = 2`，`y'|_{x=0} = 1`

### 6. 求参数

已知函数 `y = e^{rx}` 是微分方程 `y'' + 3y' + 2y = 0` 的解，求常数 `r` 的值。

### 7. 应用题

已知一条曲线通过坐标原点，并且在该曲线上任一点 `M(x, y)` 处的切线斜率为 `3x²`，求该曲线的方程。

**做题步骤建议：**
1. **判断阶数**：数方程中出现的最高阶导数是几阶。
2. **验证解**：对给定的函数求导，将 `y`, `y'`, `y''` 等代入原方程，看等式是否恒成立。
3. **直接积分法求通解**：
   - 对 `y' = f(x)`，直接积分一次得通解。
   - 对 `y'' = f(x)`，积分两次，每次积分加一个任意常数。
4. **求特解**：先求通解，再将初始条件代入，确定任意常数的值。
5. **应用题**：根据题意建立微分方程和初始条件，然后求解。
6. 打开 [AI 高数学习助手](https://math-learning-assistant.streamlit.app/)，输入答案让 AI 诊断。

**常见误区提醒：**
- ❌ **遗漏绝对值**：积分 `∫ 1/x dx = ln|x| + C`，不能只写 `ln x`。
- ❌ **忘记任意常数**：每次不定积分都必须加上积分常数，二阶方程积两次分会出现**两个独立的**任意常数 `C₁` 和 `C₂`。
- ❌ **混淆通解与特解**：通解含任意常数，特解不含。
