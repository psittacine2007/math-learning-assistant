## 🎨 生活类比

**偏导数是什么？——登山者的“方向性感受”**

想象你正站在一座起伏的山坡上（这座山就是二元函数的图像）。你举起指南针，想了解脚下的坡度。

- **对 x 方向的偏导数 (`f_x`)**：你命令自己**只准向东/西方向走**，感受脚下的陡峭程度。这时你完全不在意南北方向的地形变化，就当它是平坦的。你感受到的沿东西方向的坡度，就是对 x 的偏导数。
- **对 y 方向的偏导数 (`f_y`)**：同样，你命令自己**只准向南/北方向走**，感受沿南北方向的坡度，不管东西方向。你感受到的沿南北方向的坡度，就是对 y 的偏导数。

**一句话理解**：偏导数就是**固定其他所有变量，只看其中一个变量变化时函数的变化率**。就像在错综复杂的山路中，你只关注“正东方向”的坡度，把其他方向暂时“冻结”起来。

## 🧭 几何直观

- **曲面上的曲线**：在三维空间中，二元函数 `z = f(x, y)` 是一张曲面。偏导数 `f_x(x_0, y_0)` 的几何意义是：用平面 `y = y_0`（一个垂直于 y 轴的竖直平面）去“切”这张曲面，得到一条曲线。这条曲线在点 `M_0` 处的切线，对 x 轴的斜率就是 `f_x(x_0, y_0)`。
- **另一个方向的切线**：同理，偏导数 `f_y(x_0, y_0)` 是用平面 `x = x_0` 去切曲面，得到的曲线在 `M_0` 处的切线对 y 轴的斜率。
- **本质**：偏导数将**空间的曲面问题**，通过“冻结”一个变量，降维成了**平面上的曲线问题**。你可以想象用两把互相垂直的“激光刀”（平面 `y = y_0` 和 `x = x_0`）去切那个曲面，切出来的两道“伤口”的陡峭程度，就是两个偏导数。

## 📐 严格定义

### 8.2.1 偏导数的定义

**1. 定义**

设函数 `z = f(x, y)` 在点 `(x_0, y_0)` 的某一邻域内有定义。当 `y` 固定在 `y_0` 时，`f(x, y_0)` 是 `x` 的一元函数。如果极限

$$\lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$

存在，则称此极限为函数 `z = f(x, y)` 在点 `(x_0, y_0)` 处对 `x` 的**偏导数**，记作

$$\left. \frac{\partial z}{\partial x} \right|_{(x_0, y_0)}, \quad \left. \frac{\partial f}{\partial x} \right|_{(x_0, y_0)}, \quad z_x(x_0, y_0), \quad \text{或} \quad f_x(x_0, y_0).$$

类似地，函数 `z = f(x, y)` 在点 `(x_0, y_0)` 处对 `y` 的偏导数定义为

$$\lim_{\Delta y \to 0} \frac{f(x_0, y_0 + \Delta y) - f(x_0, y_0)}{\Delta y},$$

记作

$$\left. \frac{\partial z}{\partial y} \right|_{(x_0, y_0)}, \quad \left. \frac{\partial f}{\partial y} \right|_{(x_0, y_0)}, \quad z_y(x_0, y_0), \quad \text{或} \quad f_y(x_0, y_0).$$

**2. 偏导函数**

如果函数 `z = f(x, y)` 在区域 `D` 内每一点 `(x, y)` 都有偏导数 `f_x(x, y)` 和 `f_y(x, y)`，则它们也是 `x, y` 的二元函数，称为**偏导函数**，简称偏导数。

$$f_x(x, y) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x, y) - f(x, y)}{\Delta x},$$

$$f_y(x, y) = \lim_{\Delta y \to 0} \frac{f(x, y + \Delta y) - f(x, y)}{\Delta y}.$$

**3. 计算方法**

求 `f_x` 时，**把 `y` 看作常数**，对 `x` 求导；求 `f_y` 时，**把 `x` 看作常数**，对 `y` 求导。

**4. 偏导数的几何意义**

- `f_x(x_0, y_0)` 是曲面 `z = f(x, y)` 被平面 `y = y_0` 所截得的曲线在点 `M_0(x_0, y_0, f(x_0, y_0))` 处的切线对 `x` 轴的斜率。
- `f_y(x_0, y_0)` 是曲面 `z = f(x, y)` 被平面 `x = x_0` 所截得的曲线在点 `M_0` 处的切线对 `y` 轴的斜率。

**5. 连续性与偏导数的关系**

- **偏导数存在推不出连续**。例如，函数

$$f(x, y) = \begin{cases} \frac{xy}{x^2 + y^2}, & x^2 + y^2 \neq 0 \\ 0, & x^2 + y^2 = 0 \end{cases}$$

在点 `(0,0)` 处的两个偏导数 `f_x(0,0)` 和 `f_y(0,0)` 均为 0，但该函数在 `(0,0)` 处并不连续（因为极限不存在）。

- **连续推不出偏导数存在**。例如，函数 `f(x, y) = \sqrt{x^2 + y^2}` 在点 `(0,0)` 处连续，但 `f_x(0,0)` 和 `f_y(0,0)` 均不存在（因为 `|x|/x` 的极限不存在）。

这说明多元函数中，**可偏导**与**连续**是相互独立的两个概念，这和一元函数大不相同。

### 8.2.2 高阶偏导数

**1. 定义**

偏导函数的偏导数称为**二阶偏导数**。共有四种：

$$\frac{\partial}{\partial x} \left( \frac{\partial z}{\partial x} \right) = \frac{\partial^2 z}{\partial x^2} = f_{xx},$$

$$\frac{\partial}{\partial y} \left( \frac{\partial z}{\partial x} \right) = \frac{\partial^2 z}{\partial x \partial y} = f_{xy},$$

$$\frac{\partial}{\partial x} \left( \frac{\partial z}{\partial y} \right) = \frac{\partial^2 z}{\partial y \partial x} = f_{yx},$$

$$\frac{\partial}{\partial y} \left( \frac{\partial z}{\partial y} \right) = \frac{\partial^2 z}{\partial y^2} = f_{yy}.$$

其中 `f_{xy}` 和 `f_{yx}` 称为**混合偏导数**。二阶及以上的偏导数统称**高阶偏导数**。

**2. 混合偏导数与次序无关的条件**

**定理 8.2.1** 若函数 `f(x, y)` 的两个混合偏导数 `f_{xy}(x, y)` 和 `f_{yx}(x, y)` 都在点 `(x_0, y_0)` 处连续，则

$$f_{xy}(x_0, y_0) = f_{yx}(x_0, y_0).$$

对于更高阶的混合偏导数，在连续的条件下也与求导次序无关。

## 🧪 核心概念对比

| 概念 | 一元函数 | 二元函数 |
|------|---------|----------|
| **导数/偏导数** | 函数在一点的变化率 | 函数沿坐标轴方向的变化率 |
| **可导与连续** | 可导必连续 | 可偏导推不出连续 |
| **二阶导数** | 只有一个 `f''(x)` | 有四个：`f_{xx}, f_{xy}, f_{yx}, f_{yy}` |
| **混合导数** | 无 | 连续时与次序无关 |

## 📜 历史渊源

**问题背景**：18世纪，随着力学和流体动力学的发展，科学家们需要同时处理多个变化因素。例如，研究琴弦的振动，弦上每一点的位移不仅取决于位置 `x`，还取决于时间 `t`。这就需要一种数学工具来描述“函数对其中一个变量的变化率，而把其他变量固定”。

**关键突破**：瑞士数学家**欧拉**在18世纪30年代研究流体力学时，首次系统地使用了偏导数，并引入了符号 `∂`。法国数学家**克莱罗**在1739年证明了著名的克莱罗定理（混合偏导数在连续条件下与次序无关），标志着多元函数微分学开始成为独立的学科。

**深远影响**：偏导数是现代科学和工程学的基石。物理学中的所有场方程（如麦克斯韦方程组）、热传导方程、波动方程，都是用偏导数写成的偏微分方程。在经济学中，偏导数用于边际分析；在机器学习中，偏导数是梯度下降法的核心，驱动了所有神经网络的训练。

## 🔗 发展脉络


> 一元函数导数
> → 偏导数（固定其他变量）
> → 高阶偏导数、混合偏导数
> → 全微分（联系所有偏导数）→ 梯度与方向导数
> → 现代：偏微分方程、最优化理论、机器学习中的反向传播

---

## ⚠️ 本节概念的局限性

- **方向局限性**：偏导数只能描述函数沿坐标轴方向的变化，无法直接知道沿其他方向的变化情况（这需要“方向导数”来补充）。
- **无法保证连续性**：如前所述，偏导数存在连连续性都无法保证，更无法保证函数的光滑性。
- **信息不完整**：知道所有的偏导数，并不等于理解了函数在局部的全部几何性质（比如旋转后的变化率）。

> 💡 这些局限催生了后续更强大的工具：**全微分**可以刻画函数在局部的线性近似，**梯度**能将所有方向的变化率统一到一个向量中。

## 📝 习题

1. **求下列函数的一阶偏导数：**

   (1) `z = xy + x/y`

   (2) `z = arcsin(x / sqrt(x^2 + y^2))`

   (3) `z = (x^2 + y^2) e^{-arctan(y/x)}`

   (4) `z = x^y * y^x`

   (5) `f(u, v) = ln(u + ln v)`

   (6) `f(x, y) = \int_x^y e^{t^2} dt`

   (7) `u = x^y`

   (8) `u = sin(x_1 + 2x_2 + ... + n x_n)`

2. **求下列函数在指定点处的一阶偏导数：**

   (1) `z = x + (y - 1) arcsin(sqrt(x/y))`，点 `(0, 1)`

   (2) `z = x^2 e^y + (x - 1) arctan(y/x)`，点 `(1, 0)`

3. 求曲线 `z = (x^2 + y^2)/4` 在点 `(2, 4, 5)` 处的切线对于 `x` 轴的倾斜角。

4. 设 `f(x, y) = { xy / sqrt(x^2 + y^2), x^2 + y^2 ≠ 0; 0, x^2 + y^2 = 0 }`，证明 `f(x, y)` 在点 `(0, 0)` 处连续且偏导数存在。

5. **求下列函数所有的二阶偏导数：**

   (1) `f(x, y) = x^y`

   (2) `f(x, y) = arctan(y/x)`

   (3) `z = x^{ln y}`

6. **求下列函数指定的高阶偏导数：**

   (1) `z = x ln(xy)`，求 `∂³z / ∂x²∂y` 和 `∂³z / ∂x∂y²`

   (2) `u = x^a y^b z^c`，求 `∂⁶u / ∂x ∂y² ∂z³`

7. 证明 `r = sqrt(x^2 + y^2 + z^2)` 满足方程 `∂²r/∂x² + ∂²r/∂y² + ∂²r/∂z² = 2/r`。
