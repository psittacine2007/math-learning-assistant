## 🎨 生活类比

想象你正在一个陌生的城市旅行。你打开手机上的**气温分布图**——地图上的每一个点（经度，纬度）都对应着一个温度值。

- 你可以指着地图上任意一个位置问：“这里的温度是多少？”只要那个位置在地图范围内，就一定能得到一个确定的答案。这就是**多元函数**的核心：**多个输入，唯一输出**。
- 当你从城市中心向郊区移动时，温度通常会**平滑地变化**，不会从30度瞬间跳到零下10度。这就是**连续性**的直觉。
- 当你不断靠近一个特定地点（比如市中心广场）时，温度值会越来越接近广场上的实际温度。这就是**极限**的直觉。

**一句话理解**：多元函数就像一张“天气地图”，每个位置对应一个数值，而极限和连续性描述的是这张地图是否“平滑无裂缝”。

## 🧭 几何直观

**平面点集**：把定义域想象成桌面上的一个区域。它可以是一个圆盘（圆邻域）、一个矩形、或者更复杂的形状。区域的边界就像桌子的边缘，区域内部就是桌面本身。

**二元函数的图像**：在三维空间中，二元函数 `z = f(x, y)` 的图像是**一张悬浮在 xy 平面上方的曲面**。
- 你可以想象把定义域（桌面上的一个区域）向上或向下“拉扯”，形成山峰、山谷、鞍部等地形。
- 曲面上每一个点的高度，就是函数值。

**极限的几何意义**：当你在定义域内从**任意方向**逼近一个点时，曲面上对应点的高度都趋近于同一个值。如果沿不同路径（比如沿 x 轴走 vs. 沿 y=x 对角线走）逼近时高度不同，极限就不存在。

**连续性的几何意义**：曲面在这一点是**连着的**，没有断裂、没有空洞。如果你用手指在曲面上划过，不会“踩空”掉下去。

## 📐 严格定义

### 8.1.1 平面点集

- **邻域**：点 `P₀(x₀, y₀)` 的 `δ` 邻域 `U(P₀, δ)` 是指以 `P₀` 为圆心、`δ` 为半径的开圆盘（不包含圆周）。
  $$U(P_0, \delta) = \{(x, y) \mid (x - x_0)^2 + (y - y_0)^2 < \delta^2\}$$

- **内点**：存在一个邻域完全包含在集合内的点。
- **边界点**：任何邻域内既有集合内的点又有集合外的点。
- **开集**：所有点都是内点。**闭集**：包含所有边界点。
- **区域**：连通的开集。

### 8.1.2 二元函数的概念

设 `D` 是平面上的一个非空点集。如果对于 `D` 中每一点 `(x, y)`，按照某种法则 `f`，都有唯一确定的实数 `z` 与之对应，则称 `f` 为定义在 `D` 上的**二元函数**，记作：

$$z = f(x, y), \quad (x, y) \in D$$

其中 `x, y` 称为**自变量**，`z` 称为**因变量**，`D` 称为**定义域**。

### 8.1.3 二元函数的极限

设函数 `f(x, y)` 在点 `P₀(x₀, y₀)` 的某个去心邻域内有定义。如果存在常数 `A`，使得当点 `P(x, y)` 以**任意方式**无限趋近于 `P₀` 时，`f(x, y)` 都无限趋近于 `A`，则称 `A` 为 `f(x, y)` 当 `(x, y) → (x₀, y₀)` 时的极限，记作：

$$\lim_{(x, y) \to (x_0, y_0)} f(x, y) = A$$

**⚠️ 关键点**：二重极限要求沿**任何路径**逼近时极限都相等。沿不同路径得到不同极限值 → 极限不存在。

**判别极限不存在的方法**：找两条不同路径，使极限值不同。
- 常用的试探路径：沿 `y = kx`、沿 `y = x²`、沿 `x = 0` 或 `y = 0`。

### 8.1.4 二元函数的连续性

函数 `f(x, y)` 在点 `P₀(x₀, y₀)` 处连续，必须同时满足：

1. 函数在 `P₀` 处**有定义**：`f(x₀, y₀)` 存在。
2. **极限存在**：$$\lim_{(x, y) \to (x_0, y_0)} f(x, y)$$ 存在。
3. **极限值等于函数值**：$$\lim_{(x, y) \to (x_0, y_0)} f(x, y) = f(x_0, y_0)$$

如果 `f(x, y)` 在定义域 `D` 内每一点都连续，则称 `f` 在 `D` 上连续。

## 🧪 核心概念对比

| 概念 | 一元函数 | 二元函数 |
|------|---------|----------|
| **定义域** | 数轴上的区间 | 平面上的区域 |
| **图像** | 平面上的一条曲线 | 空间中的一张曲面 |
| **极限** | 左右极限相等 | 沿**所有路径**极限相等 |
| **连续** | 极限 = 函数值 | 极限 = 函数值（且要求沿所有路径） |
| **间断** | 点断裂 | 点断裂、线断裂 |

## 📜 历史渊源

**问题背景**：17世纪，牛顿和莱布尼茨创立了微积分，但当时处理的都是单变量函数（如 `y = f(x)`）。随着物理学研究的发展——从单质点的运动扩展到流体、电场、弹性体的分析——科学家们发现必须同时考虑多个变量。例如，一个房间的温度不仅随时间变化，还随位置变化：`T = f(x, y, z, t)`。

**关键突破**：18世纪，欧拉、克莱罗、达朗贝尔等人在研究连续介质力学时，系统发展了多元函数的微分学。欧拉提出了偏导数的概念，克莱罗证明了混合偏导数的次序可交换条件（克莱罗定理）。19世纪，柯西和魏尔斯特拉斯用更严谨的极限语言重构了分析学，多元函数的极限和连续性才被严格定义。

**深远影响**：多元函数分析是所有现代工程和物理学科的数学语言——流体力学中的速度场、电磁学中的电势场、机器学习中的损失函数曲面，都是多元函数的实例。

## ⚠️ 本节概念的局限性

- **极限存在性的判定复杂**：一维情形只需检查左右极限，而多维情形必须考虑所有可能路径，实际验证常常很困难。
- **连续性的直观容易误导**：二元函数的连续性并不能保证在任一截面上都连续（反例：`f(x, y) = y / (x² + y²)` 在原点附近沿不同方向行为不同）。
- **定义域的复杂性**：平面区域可以非常复杂（多连通、无界、不连通），不是所有函数都有简单的解析定义域。

> 💡 这些局限催生了后续更深入的分析工具：隐函数定理、一致连续性、紧致集上的性质等，将在后续章节中逐步展开。

**(3)** $$u = \sqrt{R^2 - x^2 - y^2 - z^2} + \frac{1}{\sqrt{x^2 + y^2 + z^2 - r^2}} \quad (R > r > 0)$$

**(4)** $$u = \arccos\frac{z}{\sqrt{x^2 + y^2}}$$

### 2. 求下列多元函数的极限

**(1)** $$\lim_{x \to 1 \atop y \to 0} \frac{\ln(x + e^y)}{\sqrt{x^2 + y^2}}$$

**(2)** $$\lim_{x \to 0 \atop y \to 0} \frac{2 - \sqrt{xy + 4}}{xy}$$

**(3)** $$\lim_{x \to 0 \atop y \to 0} \frac{\sin(xy)}{x}$$

**(4)** $$\lim_{x \to 0 \atop y \to 0} \frac{1 - \cos(x^2 + y^2)}{(x^2 + y^2) e^{x^2 y^2}}$$

**(5)** $$\lim_{x \to 0 \atop y \to 0} (x^2 + y^2)^{xy}$$

---

### 3. 证明下列极限不存在

**(1)** $$\lim_{x \to 0 \atop y \to 0} \frac{x + y}{x - y}$$

**(2)** $$\lim_{x \to 0 \atop y \to 0} \frac{x^2 y^2}{x^2 y^2 + (x - y)^2}$$

---

### 4. 讨论下列函数在点 (0,0) 处的连续性

**(1)**
$$f(x, y) = \begin{cases} (x^2 + y^2) \ln(x^2 + y^2), & x^2 + y^2 \neq 0 \\ 0, & x^2 + y^2 = 0 \end{cases}$$

**(2)**
$$f(x, y) = \begin{cases} (x + y) \cos\frac{1}{x}, & x \neq 0 \\ 0, & x = 0 \end{cases}$$

**(3)**
$$f(x, y) = \begin{cases} \frac{2xy}{x^2 + y^2}, & x^2 + y^2 \neq 0 \\ 0, & x^2 + y^2 = 0 \end{cases}$$
