## 🎨 生活类比

**隐函数：藏在方程背后的函数关系**

想象你参加一个神秘的化装舞会，所有的宾客（变量 `x`, `y`, `z`）都戴着面具，你无法直接看到他们的脸。但是，有一条规则（方程 `F(x, y) = 0` 或 `F(x, y, z) = 0`）限制着他们之间必须维持的某种平衡。

- 你轻轻推了推 `x`（让 `x` 发生微小变化），你发现 `y` 被迫跟着移动，以维持方程的平衡。虽然你没有看到 `y = f(x)` 这张脸（显函数表达式），但你知道了 `y` 的移动速度和方向——这就是**隐函数求导**。
- 方程 `x² + y² = 1` 确定了一个圆。在点 `(0, 1)` 附近，`y` 可以唯一地表现为 `x` 的函数（即上半圆 `y = √(1 - x²)`），但在点 `(1, 0)` 附近就做不到了——因为圆的切线是竖直的，`y` 不能随 `x` 变化了。这说明**隐函数的存在是局部的，且有条件**。

**一句话理解**：隐函数求导法，就是在**不揭开函数“显式面具”**的情况下，直接通过方程平衡条件，找到变量之间的瞬时变化率。

## 🧭 几何直观

- **一个方程 `F(x, y) = 0`**：在二维平面上，`F(x, y) = 0` 通常是一条曲线。隐函数存在定理的条件 `F_y ≠ 0` 意味着曲线在该点的切线**不是竖直的**。这时，在局部范围内，曲线可以用一个 `y = f(x)` 的单值函数来描述。`dy/dx = -F_x/F_y` 正是切线的斜率。
- **一个方程 `F(x, y, z) = 0`**：在三维空间中，`F(x, y, z) = 0` 通常是一个曲面。条件 `F_z ≠ 0` 意味着曲面在该点的法向量**不平行于 xy 平面**，因此曲面在局部可以表示为 `z = f(x, y)` 的显式形式。`∂z/∂x = -F_x/F_z` 和 `∂z/∂y = -F_y/F_z` 分别是曲面在该点的切平面在 x 和 y 方向的斜率。
- **方程组情形**：曲线是两张曲面的交线，变量间的依赖关系更复杂，但核心思想不变——利用雅可比行列式不为零的条件，保证局部可以解出指定的函数关系。

## 📐 严格定义

### 8.5.1 一个方程的情况

**定理 8.5.1 (二元方程确定一元隐函数)**
设函数 `F(x, y)` 在点 `P₀(x₀, y₀)` 的某一邻域内有一阶连续偏导数，且 `F(x₀, y₀) = 0`，`F_y(x₀, y₀) ≠ 0`，则方程 `F(x, y) = 0` 在 `P₀` 的某一邻域内能唯一确定一个单值可导函数 `y = f(x)`，满足 `y₀ = f(x₀)`，且

$$\frac{dy}{dx} = -\frac{F_x}{F_y}.$$

**推导**：将 `y = f(x)` 代入方程得 `F(x, f(x)) ≡ 0`，两边对 `x` 求导，利用链式法则：
$$\frac{\partial F}{\partial x} + \frac{\partial F}{\partial y} \cdot \frac{dy}{dx} = 0$$
再由 `F_y ≠ 0` 即得公式。

**几何意义**：`F_y(x₀, y₀) ≠ 0` 保证曲线 `F(x, y) = 0` 在 `P₀` 附近不是竖直切线，可唯一表示为 `y = f(x)`。

**定理 8.5.2 (三元方程确定二元隐函数)**
设函数 `F(x, y, z)` 在点 `P₀(x₀, y₀, z₀)` 的某一邻域内有一阶连续偏导数，且 `F(x₀, y₀, z₀) = 0`，`F_z(x₀, y₀, z₀) ≠ 0`，则方程 `F(x, y, z) = 0` 在 `P₀` 的某一邻域内能唯一确定一个单值有连续偏导数的二元函数 `z = f(x, y)`，满足 `z₀ = f(x₀, y₀)`，且

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \qquad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}.$$

### 8.5.2 方程组的情形

**定理 8.5.3 (两个三元方程确定两个一元隐函数)**
设 `F(x, y, z)` 和 `G(x, y, z)` 在点 `P₀(x₀, y₀, z₀)` 的某邻域内有一阶连续偏导数，满足 `F(P₀) = G(P₀) = 0`，且雅可比行列式

$$J = \frac{\partial (F, G)}{\partial (y, z)} = \begin{vmatrix} F_y & F_z \\ G_y & G_z \end{vmatrix} \neq 0,$$

则在 `P₀` 附近唯一确定单值可导函数 `y = f(x)` 和 `z = g(x)`，且

$$\frac{dy}{dx} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (x, z)}, \qquad \frac{dz}{dx} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (y, x)}.$$

**推导**：方程组两边对 `x` 求导得
$$\begin{cases} F_x + F_y y' + F_z z' = 0 \\ G_x + G_y y' + G_z z' = 0 \end{cases}$$
用克莱姆法则解出 `y'` 和 `z'`。

**定理 8.5.4 (两个四元方程确定两个二元隐函数)**
设 `F(x, y, u, v)` 和 `G(x, y, u, v)` 满足类似条件，且 `J = ∂(F, G)/∂(u, v) ≠ 0`，则唯一确定 `u = u(x, y)`、`v = v(x, y)`，且

$$\frac{\partial u}{\partial x} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (x, v)}, \quad \frac{\partial v}{\partial x} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (u, x)},$$
$$\frac{\partial u}{\partial y} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (y, v)}, \quad \frac{\partial v}{\partial y} = -\frac{1}{J}\frac{\partial (F, G)}{\partial (u, y)}.$$

> **总结**：记忆公式不必死记，掌握**对方程两边同时求偏导、再解出目标导数**的方法即可。

## 🧪 核心概念对比

| 概念 | 显函数 | 隐函数 |
|------|--------|--------|
| **表达式** | `y = f(x)` 或 `z = f(x, y)` | `F(x, y) = 0` 或 `F(x, y, z) = 0` |
| **求导方式** | 直接求导 | 方程两边求导，解出导数 |
| **局部性** | 全局定义 | 需满足隐函数定理条件才局部存在 |
| **核心条件** | 无额外条件 | 偏导数 `F_y ≠ 0` 或 `F_z ≠ 0` |
| **几何意义** | 曲线/曲面显式给出 | 曲面截出等值线/面 |

## 📜 历史渊源

**问题背景**：17-18世纪，数学家们经常遇到无法解出显式表达式的方程，例如开普勒方程 `x = y - e sin y` 就无法用初等函数写出 `y = f(x)`。但天文学家需要知道行星位置随时间的瞬时变化率。因此，需要一种方法**不求解方程本身，直接求导**。

**关键突破**：牛顿和莱布尼茨在创立微积分时已经使用了隐函数求导的思想，但没有严格的理论基础。18世纪，欧拉和克莱罗在研究中大量运用隐函数。直到19世纪，柯西和魏尔斯特拉斯建立了严格的极限理论，才为隐函数存在定理提供了完整证明。雅可比（Jacobi）引入了行列式工具，将其推广到方程组情形。

**深远影响**：隐函数定理是现代微分几何、非线性分析和经济学的基石。它保证了在满足一定条件下，我们可以通过局部线性化来理解复杂的非线性关系。在物理学中，热力学麦克斯韦关系式的推导就依赖隐函数求导。

> → 三元方程确定二元函数
> → 方程组情形（雅可比行列式）
> → 现代：隐函数定理在微分几何、优化理论中的应用

## ⚠️ 本节概念的局限性

- **局部性**：隐函数定理只能保证在**局部邻域**内存在隐函数，无法拓展到全局。例如圆的例子中，整个圆不能用单一函数 `y = f(x)` 表示。
- **条件要求**：定理要求偏导数连续且某个偏导数不为零，若不满足这些条件，隐函数可能不存在或不可导。
- **计算复杂度**：对于多个方程和多个变量的情形，手动计算雅可比行列式并解导数会变得繁琐。

> 💡 这些局限推动了**隐函数定理的推广**（如Banach空间的隐函数定理）和**数值方法**（如牛顿迭代法求解隐式方程）。

## 📝 习题

### 1. 求下列方程所确定的隐函数的导数或偏导数

**(1)** `sin y - e^x - xy² = 0`，求 `dy/dx`

**(2)** `ln √(x² + y²) = arctan(y/x)`，求 `d²y/dx²`

**(3)** `z = e^{xy}`，求 `∂z/∂x`，`∂z/∂y`

**(4)** `z + e^z = xy`，求 `∂²z/∂x∂y`

### 2. 设 `x = x(y, z)`, `y = y(x, z)`, `z = z(x, y)` 都是由方程 `F(x, y, z) = 0` 所确定的具有连续偏导数的函数，证明

$$\frac{\partial x}{\partial y} \cdot \frac{\partial y}{\partial z} \cdot \frac{\partial z}{\partial x} = -1.$$

### 3. 设函数 `z = z(x, y)` 由方程 `F(x + z/y, y + z/x) = 0` 所确定，证明

$$x \frac{\partial z}{\partial x} + y \frac{\partial z}{\partial y} = z - xy.$$

### 4. 求由下列方程组所确定的函数的导数或偏导数

**(1)** $$\begin{cases} z = x² + y² \\ x² + 2y² + 3z² = 20 \end{cases}$$，求 `dy/dx`，`dz/dx`

**(2)** $$\begin{cases} x² + y² - uv = 0 \\ xy² - u² + v² = 0 \end{cases}$$，求 `∂u/∂x`，`∂u/∂y`，`∂v/∂x`，`∂v/∂y`

**(3)** $$\begin{cases} u = f(ux, v + y) \\ v = g(u - x, v² y) \end{cases}$$，其中 `f, g` 有一阶连续偏导数，求 `∂u/∂x`，`∂v/∂x`

### 5. 设 `y = f(x, t)`，`F(x, y, t) = 0`，其中 `f, F` 有连续一阶偏导数，证明

$$\frac{dy}{dx} = \frac{f_x F_t - f_t F_x}{F_t + f_t F_y}.$$
