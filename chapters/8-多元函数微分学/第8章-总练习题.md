## 📝 总练习题

### 1. 概念辨析

在“充分非必要”、“必要非充分”、“充要”、“既不充分又不必要”中选择一个填入空格：

**(1)** `f(x, y)` 在点 `(x, y)` 可微是 `f(x, y)` 在该点连续的 ______ 条件；

**(2)** `z = f(x, y)` 在点 `(x, y)` 的偏导数 `∂z/∂x`、`∂z/∂y` 存在是 `f(x, y)` 在该点可微分的 ______ 条件；

**(3)** `f(x, y)` 在点 `(x, y)` 连续是 `f(x, y)` 在该点的偏导数存在的 ______ 条件；

**(4)** `z = f(x, y)` 在点 `(x, y)` 连续且偏导数存在是 `f(x, y)` 在该点可微分的 ______ 条件；

**(5)** `z = f(x, y)` 的偏导数 `∂z/∂x`、`∂z/∂y` 在点 `(x, y)` 存在且连续是 `f(x, y)` 在该点可微分的 ______ 条件；

**(6)** `z = f(x, y)` 的两个二阶混合偏导数 `∂²z/∂x∂y` 及 `∂²z/∂y∂x` 在区域 `D` 内连续是这两个混合偏导数在 `D` 内相等的 ______ 条件。

### 2. 证明极限不存在

证明极限 $$\lim_{x \to 0 \atop y \to 0} \frac{xy^2}{x^2 + y^4}$$ 不存在。

### 3. 证明有界性

证明：若 `f(x, y)` 在全平面连续，且 $$\lim_{x^2 + y^2 \to +\infty} f(x, y) = A$$ 存在，则 `f(x, y)` 是有界函数。

### 4. 求偏导函数

设

$$
f(x, y) = 
\begin{cases} 
\frac{x^2 y}{x^2 + y^2}, & x^2 + y^2 \neq 0 \\
0, & x^2 + y^2 = 0 
\end{cases}
$$

求 $f_x(x, y)$ 和 $f_y(x, y)$（注意在原点需用定义）。

### 5. 求一阶及二阶偏导数

**(1)** $z = \ln(x + y^2)$

**(2)** $z = x^y$

### 6. 证明连续、偏导存在但不可微

设

$$
f(x, y) = 
\begin{cases} 
\frac{x^2 y^2}{(x^2 + y^2)^{3/2}}, & x^2 + y^2 \neq 0 \\
0, & x^2 + y^2 = 0 
\end{cases}
$$

证明 $f(x, y)$ 在点 $(0, 0)$ 处连续且偏导数存在，但不可微分。

### 7. 复合函数求导

设 `z = f(x, y)` 在点 `(1, 1)` 处可微，且 `f(1, 1) = 1`，`f_x(1, 1) = 2`，`f_y(1, 1) = 3`。`φ(x) = f(x, f(x, x))`，求 `d/dx [φ³(x)]` 在 `x = 1` 处的值。

### 8. 综合链式法则与隐函数

设 `u = f(x, y, z)` 有连续的一阶偏导数，又函数 `y = y(x)`、`z = z(x)` 分别由 `e^{xy} - xy = 2` 和 `e^x = ∫_0^x (sin t)/t dt` 确定，求 `du/dx`。

### 9. 方程组确定的隐函数

求由方程组

$$
\begin{cases} 
x = u + v \\ 
y = u^2 + v^2 
\end{cases}
$$

及 $z = u^3 + v^3$ 所确定的隐函数 $z = f(x, y)$ 在点 $(1, 1)$ 处的偏导数。
### 10. 利用条件确定函数

设 `z = e^{-x} - f(x - 2y)`，当 `y = 0` 时 `z = x²`，求 `∂z/∂x`。

### 11. 空间曲线的切线与法平面

求螺旋线 `x = a cos θ, y = a sin θ, z = bθ` 在点 `(a, 0, 0)` 处的切线及法平面方程。

### 12. 曲面的法线

在曲面 `z = xy` 上求一点，使这点处的法线垂直于平面 `x + 3y + z + 9 = 0`，并写出这法线的方程。

### 13. 证明切平面性质

证明：曲面 `z = x f(y/x)` 的所有切平面都经过坐标原点。

### 14. 方向导数与梯度

设 `x` 轴正方向到方向 `l` 的转角为 `φ`，求函数 `f(x, y) = x² - xy + y²` 在点 `(1, 1)` 处沿方向 `l` 的方向导数，并分别确定转角 `φ`，使这导数有 (1) 最大值；(2) 最小值；(3) 等于 0。

### 15. 方向导数综合

过曲面 `2x² + 3y² + z² = 6` 上点 `P₀(1, 1, 1)` 处指向外侧的法向量为 `n`，求函数 `u = √(6x² + 8y²) / z` 在点 `P₀` 处沿方向 `n` 的方向导数。

### 16. 条件极值应用题

在椭圆 `x² + 4y² = 4` 上求一点，使其到直线 `2x + 3y - 6 = 0` 的距离最短。


## 🧠 解题指引（使用 AI 助手）

**如何使用 AI 助手高效复习总练习题？**

1. **先独立思考，再求助 AI**。尝试自己做一遍，遇到卡壳的题目，不要直接看答案。
2. **把具体题目和你的思路一起发给 AI**。例如：
   > “总练习题第6题：我证明了连续性和偏导数存在，但在证不可微时卡住了，我的思路是...，请帮我指出哪里出错了。”
3. **让 AI 帮你诊断错误类型**。AI 会判断你是**计算错误**、**概念混淆**（如分不清充分必要条件），还是**方法错误**（如不会使用定义证明不可微）。
4. **针对薄弱点回顾章节**。AI 会建议你回到具体哪一节重新学习（例如，“你对可微的充分条件和必要条件的理解有混淆，建议回顾 8.3 节”）。

**重点题型分析**：

- **第1题**：全面检测你对连续、偏导数、可微三者关系的理解。这是本章最重要的逻辑链。
- **第2、6题**：检验你用定义证明极限、连续性、可微性的基本功力。
- **第7、8、9题**：综合运用链式法则、隐函数求导和方程组情形的雅可比行列式。
- **第11、12、15题**：几何应用的综合题，涉及切平面、法线、方向导数和梯度的联合使用。
- **第14题**：方向导数和梯度的经典题，直接检验你对“梯度方向即最大方向导数方向”的理解。
- **第16题**：条件极值的应用题，用拉格朗日乘数法或几何方法求解。
