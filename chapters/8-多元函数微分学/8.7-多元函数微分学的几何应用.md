## 🎨 生活类比

**切线与法平面：过山车的轨道与安全带**

想象你正坐在一辆飞驰的过山车上，轨道就是空间中的一条曲线。

- **切线**：在某一瞬间，你所在那个点的运动方向——你的“前进方向”。数学上，这就是曲线在该点的**切线**。切线方向向量由你的“位置函数”对时间的导数决定。
- **法平面**：与你前进方向垂直的“安全护栏平面”。在这个平面上，你可以左右移动、上下颠簸，但绝不会有向前或向后的分量。它就像把你牢牢固定在座位上的安全带系统。

**切平面与法线：在山坡上立一块硬纸板**

再想象你站在一个光滑的山坡（曲面）上。你想在你脚底下垫一块硬纸板，让它尽可能地贴合山坡。

- **切平面**：这块硬纸板就是山坡在该点的**切平面**。它和你脚下的曲面在这一点“无限贴近”，所有经过你脚点的山坡上的曲线，它们的切线都乖乖地躺在硬纸板上。
- **法线**：你笔直地向上跳起，垂直于硬纸板的方向，就是**法线**。它指向山坡“最凸出”的方向，也是曲面在该点梯度的方向。


## 🧭 几何直观

- **空间曲线的切线**：无论曲线是以参数方程、`y = y(x), z = z(x)` 还是隐式方程组给出，我们总能找到它的**切向量**。切向量就是曲线在该点的“瞬时速度”。切线方程就是一条经过该点、方向为切向量的直线。
- **曲面的法向量与切平面**：
  - 对于显式曲面 `z = f(x, y)`，法向量可以直接从偏导数得到：`(f_x, f_y, -1)`。这正好是函数 `F(x, y, z) = f(x, y) - z` 的梯度！
  - 对于隐式曲面 `F(x, y, z) = 0`，法向量就是 `(F_x, F_y, F_z)`，也就是 `F` 的梯度。切平面是所有这些法向量“否决”的方向构成的平面。
- **统一的心法**：**梯度就是法向量**。空间曲线的切向量由参数方程求导得到；曲面的法向量由梯度得到。切线与切平面、法平面与法线，其核心都是向量的垂直与平行关系。


## 📐 严格定义

### 8.7.1 空间曲线的切线和法平面

设空间曲线 `Γ` 的参数方程为 `x = x(t), y = y(t), z = z(t)`，三个函数都可导，点 `M₀(x₀, y₀, z₀)` 对应 `t = t₀`。曲线在 `M₀` 的**切向量**为

$$\mathbf{s} = (x'(t_0), y'(t_0), z'(t_0)).$$

**切线方程**：
$$\frac{x - x_0}{x'(t_0)} = \frac{y - y_0}{y'(t_0)} = \frac{z - z_0}{z'(t_0)}.$$

**法平面方程**（过 `M₀` 且垂直于切向量）：
$$x'(t_0)(x - x_0) + y'(t_0)(y - y_0) + z'(t_0)(z - z_0) = 0.$$

**其他曲线形式**：
- 若曲线为 `y = y(x), z = z(x)`，取 `x` 为参数，切向量为 `(1, y'(x₀), z'(x₀))`。
- 若曲线由方程组 `F(x,y,z)=0, G(x,y,z)=0` 给出，则在满足雅可比行列式不全为零的点处，切向量可取为

$$\mathbf{s} = (m, n, p),$$

其中 `m = ∂(F,G)/∂(y,z)`, `n = ∂(F,G)/∂(z,x)`, `p = ∂(F,G)/∂(x,y)`（均在 `M₀` 处取值）。

### 8.7.2 曲面的切平面与法线

**1. 隐式曲面 `F(x, y, z) = 0`**

设 `M₀(x₀, y₀, z₀)` 在曲面上，`F` 的一阶偏导数在 `M₀` 连续且不同时为零。曲面在 `M₀` 的**法向量**为

$$\mathbf{n} = (F_x(M_0), F_y(M_0), F_z(M_0)).$$

**切平面方程**：
$$F_x(M_0)(x - x_0) + F_y(M_0)(y - y_0) + F_z(M_0)(z - z_0) = 0.$$

**法线方程**：
$$\frac{x - x_0}{F_x(M_0)} = \frac{y - y_0}{F_y(M_0)} = \frac{z - z_0}{F_z(M_0)}.$$

**2. 显式曲面 `z = f(x, y)`**

写成 `F(x, y, z) = f(x, y) - z = 0`，则法向量为

$$\mathbf{n} = (f_x(x_0, y_0), f_y(x_0, y_0), -1).$$

**切平面方程**：
$$f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0) - (z - z_0) = 0.$$

**法线方程**：
$$\frac{x - x_0}{f_x(x_0, y_0)} = \frac{y - y_0}{f_y(x_0, y_0)} = \frac{z - z_0}{-1}.$$


## 🧪 核心概念对比

| 概念 | 曲线 | 曲面 |
|------|------|------|
| **核心向量** | **切向量**（沿曲线方向） | **法向量**（垂直于曲面） |
| **向量来源** | 参数方程求导 | 梯度 `∇F` 或 `(f_x, f_y, -1)` |
| **“贴合的平面/直线”** | 法平面（垂直于切线） | 切平面（垂直于法线） |
| **几何意义** | 描述运动方向 | 描述局部线性近似 |
| **推广** | 三元以上曲线的切线 | n 维超曲面的切空间 |


## 📜 历史渊源

**问题背景**：17世纪，随着微积分的创立，科学家开始研究曲线和曲面的局部几何性质。如何找到曲线在某点的最佳线性近似（切线），以及曲面在某点的最佳平面近似（切平面），成为推动微分几何发展的核心问题。

**关键突破**：牛顿和莱布尼茨在创立微积分时已经能够求曲线的切线。18世纪，欧拉和蒙日将切线概念推广到空间曲线和曲面，蒙日创立了画法几何，系统地研究了曲面的切平面和法线。19世纪，高斯在研究曲面内蕴几何时，将切平面作为局部欧氏空间的替代，开创了现代微分几何。

**深远影响**：切线与切平面是局部线性化思想的几何体现，这一思想贯穿现代数学和物理。在优化中，梯度下降法就是沿目标函数的负梯度（法线）方向行走；在计算机图形学中，光照模型依赖于表面法向量；在物理学中，曲线运动的速度和加速度都是切线及其变化率的应用。


## 🔗 发展脉络

> 空间参数曲线的切线
> → 曲面由方程给出时的法向量与切平面
> → 切线与法平面、切平面与法线的对偶关系
> → 现代：微分几何中的切空间与法丛、计算机图形学中的表面渲染


## ⚠️ 本节概念的局限性

- **坐标依赖**：本节公式依赖于具体的参数化或方程形式。如果换一种参数表示，切向量或法向量的长度可能改变，但方向不变。这促使了微分几何中“几何量应与参数选取无关”的原则。
- **正则性条件**：切线存在要求切向量非零；法线存在要求法向量非零。在奇点（如锥面的顶点），这些几何对象可能不存在或不唯一。
- **仅限于一阶近似**：切线和切平面只利用了函数的一阶导数信息，在需要更高精度近似的场合（如计算弯曲程度），需要曲率等二阶工具。

> 💡 这些局限推动了**曲率与挠率**（描述曲线的弯曲和扭转）以及**曲面的第一、第二基本形式**（描述曲面的内蕴几何和外部弯曲）的研究。

**做题步骤建议：**
1. **识别类型**：分清是曲线问题还是曲面问题。
2. **曲线问题**：
   - 参数方程直接求导得切向量。
   - 隐式方程组计算三个雅可比行列式 `(m, n, p)` 作为切向量。
   - 代入公式写出切线和法平面方程。
3. **曲面问题**：
   - 隐式 `F(x,y,z)=0`：求 `(F_x, F_y, F_z)` 得法向量。
   - 显式 `z=f(x,y)`：法向量为 `(f_x, f_y, -1)`。
   - 代入公式写出切平面和法线方程。
4. **平行条件**：曲线切线与平面平行 ⇔ 切向量与平面法向量垂直（点积为零）；曲面切平面与已知平面平行 ⇔ 法向量平行（对应分量成比例）。

**常见误区提醒：**
- ❌ 混淆切线与法线、切平面与法平面。
